## ⛔ เว็บอ่านพระคัมภีร์ยังไม่เริ่มสร้าง

ตอนนี้ในที่เก็บมี **ต้นฉบับ** · **สคริปต์** · **บันทึกงาน** ที่อยู่ในโฟลเดอร์ `docs/`
และ ⭐ **เนื้อเว็บใน `content/`** ⇒ วันนี้เขียนไว้ **1 ไฟล์** คือ [`content/แหล่งข้อมูล.md`](content/แหล่งข้อมูล.md) หน้าที่บอกว่าเว็บนี้เอาพระคัมภีร์มาจากไหน
⇒ ⭐ **ตัวสร้างเว็บเป็น Nuxt แล้ว** (ใบงาน [#19](https://aimgit.aimagin.com/v3/phrakham/-/issues/19)) ⇒ ไฟล์นั้นขึ้นที่ทดลองเป็นหน้าเว็บจริง
⇒ ⛔ **แต่ยังไม่มีหน้าให้คนอ่านพระคัมภีร์สักหน้า** และ ⛔ **ยังไม่มีแบบหน้าจอ** (เป็นของใบ [#8](https://aimgit.aimagin.com/v3/phrakham/-/issues/8))

ที่อยู่ของที่ทดลอง · ด่านอัตโนมัติ · ตัวประทับคอมมิต ⇒ [`ข้อกำหนดโปรเจกต์.md`](ข้อกำหนดโปรเจกต์.md) ⛔ ไม่จดซ้ำที่นี่
