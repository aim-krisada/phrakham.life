# ฟอนต์ที่ฝากมากับเว็บ

## ทำไมต้องฝากไฟล์ฟอนต์มาเอง

ฟอนต์ที่เราไม่ได้ฝากมา เครื่องของผู้อ่านที่ไม่มีฟอนต์นั้นจะตกไปใช้ฟอนต์อะไรก็ได้ของเครื่องตัวเอง
บนวินโดวส์ภาษาไทยจะได้ Leelawadee UI หรือ Tahoma ซึ่งเราทดสอบไม่ได้เลย

ผลคือ **ตัวเลขหน้าตาที่เราวัดมาทั้งหมดใช้กับเครื่องพวกนั้นไม่ได้** ทั้งความกว้างบรรทัด
ระยะห่างบรรทัด และขนาดตัวอักษร เพราะทุกตัวเลขวัดมาจากรูปร่างของฟอนต์ที่เราฝากไว้

พี่เอมเคาะเรื่องนี้ไว้แล้วที่ [`docs/เคาะ/หน้าจอกับการอ่าน.md`](เคาะ/หน้าจอกับการอ่าน.md)
หัวข้อ *หน้าอ่าน — เคาะเพิ่ม* ว่า **ฟอนต์ต้องฝากไฟล์ไว้กับเว็บเอง**

และเราไม่ดึงจากเซิร์ฟเวอร์ของคนอื่นตอนผู้อ่านเปิดหน้า ด้วยเหตุผล 2 ข้อ
เว็บนี้ต้องอ่านได้แม้เน็ตไม่ดี และเราไม่ส่งที่อยู่ของผู้อ่านไปให้เซิร์ฟเวอร์ใคร

## เปลี่ยนจาก Sarabun เป็น Noto ชุดเดียวกับเว็บเพลง

ใบ [#174](https://aimgit.aimagin.com/v3/phrakham/-/work_items/174) เปลี่ยนฟอนต์ทั้งเว็บ
จาก Sarabun เป็นฟอนต์ชุดเดียวกับเว็บเพลง https://pleng.phrakham.life/
แล้วให้ผู้อ่านเลือกตัวอักษรไทยเองที่แผง Aa ว่าจะเอา *ไม่มีหัว* หรือ *มีหัว*

| ใช้กับ | ฟอนต์ |
| --- | --- |
| ตัวไทยแบบมีหัว **ค่าเริ่มต้น** | Noto Sans Thai Looped |
| ตัวไทยแบบไม่มีหัว | Noto Sans Thai |
| ตัวอังกฤษ ตัวเลข และคำอ่านของคำภาษาเดิม | Noto Sans |
| ลูกศร ← ↑ → ↓ | Noto Sans Math |
| ▶ ► ◄ ▾ ● ✓ ❚ | Noto Sans Symbols 2 |

**ค่าเริ่มต้นคือมีหัว** พี่เอมเคาะ 15 พ.ย. 2569 เพราะ Sarabun ที่ใช้มาก่อนเป็นตัวมีหัว
คนที่เคยเข้าเว็บจึงยังเห็นตัวมีหัวเหมือนเดิม แต่หน้าตาต่างจาก Sarabun เล็กน้อย

**ทำไมต้องมีฟอนต์เครื่องหมายอีก 2 ชุด** Sarabun มีลูกศร → กับสามเหลี่ยม ▶ อยู่ในตัว
แต่ Noto Sans ทั้งสามชุดไม่มี ด่านฟอนต์มากับเว็บจับได้เองว่า → บนหน้าแหล่งข้อมูล
กับ ▶ บนปุ่มฟัง ตกไปใช้ฟอนต์ของเครื่อง เราจึงหยิบมาจากตระกูล Noto เดียวกัน
แต่ละไฟล์เหลือแค่ไม่กี่ตัว หนักไฟล์ละราว 1.5 KB

## สัญญาอนุญาตว่าอย่างไร

ทุกชุดอยู่ใต้ **SIL Open Font License รุ่น 1.1**

สัญญานี้ให้เราเอาฟอนต์ไปใช้ ไปศึกษา ไปแก้ และแจกต่อได้ฟรี โดยมีข้อบังคับที่เกี่ยวกับเราคือ

1. เวลาแจกต่อ ต้องแจกตัวสัญญากับประกาศลิขสิทธิ์ไปพร้อมกัน
   เราจึงวางไฟล์สัญญาไว้คู่ไฟล์ฟอนต์ของมันที่ `public/fonts/<ฟอนต์>-OFL.txt`
   ซึ่งเสิร์ฟออกไปกับเว็บด้วย
2. ห้ามขายฟอนต์แยกเดี่ยว ๆ ซึ่งเราไม่ได้ทำ
3. ถ้าฟอนต์ประกาศ Reserved Font Name ไว้ ห้ามเอาชื่อนั้นไปตั้งให้ตัวที่แก้แล้ว
   **ทั้ง 5 ชุดไม่ได้ประกาศชื่อสงวนไว้เลย** ดูได้จากบรรทัดแรกของไฟล์สัญญา
   ที่เขียนแค่บรรทัดลิขสิทธิ์ ไม่มีวงเล็บต่อท้ายว่า with Reserved Font Name

ไฟล์สัญญาเราคัดไบต์มาจากต้นทางตรง ๆ ไม่ได้พิมพ์ตาม เหตุผลเดียวกับที่
[`tools/สัญญาอนุญาต.py`](../tools/สัญญาอนุญาต.py) เขียนไว้ว่า
พิมพ์เองแล้วพลาดคำเดียว เท่ากับเราแสดงสัญญาผิดจากที่เจ้าของเขียน

ทั้ง 5 ชุดขึ้นอยู่ในหน้าแหล่งข้อมูลของเว็บ หัวข้อ *ตัวอักษรบนเว็บ*

> เอกสารนี้ไม่ใช่คำแนะนำทางกฎหมาย ตัวจริงคือข้อความในไฟล์ `public/fonts/*-OFL.txt`

## ตัดอย่างไร

สั่ง `py -3.14 tools/ตัดฟอนต์.py <โฟลเดอร์พักไฟล์ต้นทาง>` เครื่องมือทำทุกขั้นเอง
และหยุดทันทีถ้าไฟล์ต้นทางที่โหลดมามีลายนิ้วมือไม่ตรงกับที่ตรึงไว้ รันซ้ำได้ไฟล์เดิมทุกไบต์

1. **ตรึงความกว้างไว้ที่ 100** ต้นทางของไทยกับอังกฤษเป็นฟอนต์แปรผัน 2 แกน คือความกว้างกับน้ำหนัก
   เว็บไม่เคยบีบหรือขยายตัวอักษร จึงตรึงแกนความกว้างทิ้ง
2. **เหลือน้ำหนัก 400 ถึง 700** เท่าที่หน้าเว็บวาดจริง ไฟล์เดียวคลุมทุกน้ำหนักในช่วงนี้
   ไม่ต้องแยกไฟล์ปกติกับไฟล์หนา
3. **เก็บเฉพาะตัวอักษรในช่วงของมัน** ไทยเก็บแค่ตัวไทย อังกฤษเก็บแค่ตัวละตินที่ข้อมูลใช้จริง
   เรานับทุกตัวใน `_data/` ก่อนเลือกช่วง เช่น คำอ่านฮีบรูใช้ ə ʾ ʿ ḥ ṣ ṭ ṯ หลายหมื่นตัว
   ส่วนตัวเวียดนามมีแค่ 3 ตัวจึงไม่เอามา ตัวที่ไม่อยู่ในช่วงจะวาดด้วยฟอนต์ของเครื่อง ไม่เป็นสี่เหลี่ยมเปล่า

ช่วงตัวอักษรในเครื่องมือต้องตรงกับ `unicode-range` ใน `app/assets/css/main.css`
แก้ที่หนึ่งแล้วต้องแก้อีกที่ด้วย

## โหลดเฉพาะฟอนต์ที่ผู้อ่านใช้

เบราว์เซอร์โหลดไฟล์ฟอนต์ก็ต่อเมื่อมีตัวหนังสือบนหน้าขอฟอนต์นั้นจริง
กองฟอนต์ของหน้ามีฟอนต์ไทยแบบเดียว คือแบบที่ผู้อ่านเลือก อีกแบบจึงไม่ถูกโหลด
อีกแบบจะโหลดตอนเดียว คือตอนผู้อ่านกางแผง Aa เพราะปุ่มต้องวาดตัวอย่าง ก ข ค ด้วยฟอนต์ของมันเอง

ห้ามใส่ `<link rel="preload">` ให้ฟอนต์ไทย เพราะมันบังคับให้โหลดทั้งที่ไม่ได้ใช้

`unicode-range` แยกไทยกับอังกฤษขาดกัน หน้าที่ไม่มีลูกศรก็ไม่โหลดไฟล์ลูกศร

## ตั้งชื่อ PK ไม่ใช้ชื่อจริงของฟอนต์

ใน CSS เราเรียกฟอนต์ว่า `PK Noto Sans Thai Looped` ไม่ใช่ `Noto Sans Thai Looped` เฉย ๆ
เหตุผลยืมมาจากเว็บเพลง v3 ซึ่งวัดไว้แล้ว ถ้าตั้งชื่อซ้ำกับฟอนต์ที่ผู้อ่านติดตั้งไว้ในเครื่อง
ของในเครื่องจะชนะ คนที่มี Noto รุ่นอื่นในเครื่องจะเห็นคนละแบบกับที่เราวัด
ชื่อที่ไม่มีเครื่องไหนมี ทำให้ทุกเครื่องได้ไฟล์ของเราแน่นอน

## จำค่าที่ผู้อ่านเลือกไว้อย่างไร

ค่าเก็บไว้ในเครื่องของผู้อ่านที่กุญแจ `pk-font` ท่าเดียวกับขนาดตัวอักษรที่เก็บไว้ที่ `pk-fs`
ไม่มีค่า หรือเครื่องจำค่าไม่ได้ เช่นหน้าต่างส่วนตัว จะได้ตัวมีหัวซึ่งเป็นค่าเริ่มต้น
รายละเอียดอยู่ที่ `app/utils/แบบตัวอักษรไทย.ts`

## ทำไมเป็น woff2

woff2 เล็กกว่า ttf มาก และเบราว์เซอร์ทุกตัวที่ยังใช้กันอยู่อ่านได้

## font-display ตั้งเป็น swap

`swap` แปลว่าตัวหนังสือขึ้นทันทีด้วยฟอนต์สำรอง แล้วสลับเป็นฟอนต์ของเราเมื่อโหลดเสร็จ
ถ้าโหลดไม่สำเร็จ ตัวหนังสือก็ยังอ่านได้ด้วยฟอนต์สำรองของเครื่อง

ไม่ใช้ `block` เพราะหน้าจะว่างเปล่าระหว่างรอ
ไม่ใช้ `optional` เพราะเน็ตช้าครั้งแรก เบราว์เซอร์จะทิ้งฟอนต์เราไปทั้งหน้าเลย

## หน้าตาที่ขยับเพราะฟอนต์ใหม่

Noto กว้างกว่า Sarabun ที่ขนาดเดียวกัน ใบ #174 จึงต้องวัดใหม่ 3 จุด ไม่ได้ผ่อนเกณฑ์ของด่านสักข้อ
ตัวเลขทุกตัวกับเหตุผลอยู่ในคอมเมนต์ข้างค่าที่แก้ ไม่จดซ้ำที่นี่

1. ขอบในของปุ่มบนแถบบนจอแคบ จาก 0.4rem เหลือ 0.3rem ใน `app/assets/css/main.css`
   ไม่งั้นจอ 320 ตัวอักษร 200% แถบบนตกเป็น 2 แถว
2. ช่องไฟในช่องฉบับของหัวคำเดิมบนจอแคบ ใน `app/assets/css/main.css`
   ไม่งั้นจอ 375 TCV กับคำเดิมตกจากซ้ายขวาเป็นบนล่าง
3. ข้อ ⑧ ของ `tools/ด่านจังหวะการอ่าน.mjs` ตรวจจอ 768 ขนาด 85% เพิ่ม
   เพราะที่ 100% ไม่มีคอลัมน์ไหนยาวเกิน 80 ตัวได้แล้ว ท่าพังของด่านเลยทำให้แดงไม่ได้

## ของที่ยังใช้ฟอนต์ของเครื่อง

ตัวกรีกกับตัวฮีบรูของคำภาษาเดิมยังวาดด้วยฟอนต์ของเครื่องเหมือนก่อนใบ #174
เพราะ Sarabun ก็ไม่มี และใบนี้ไม่ได้เพิ่มตัวเลือกฟอนต์อื่น

## ตัวเฝ้า

`tools/ด่านฟอนต์มากับเว็บ.mjs` เปิดหน้าจริงด้วยเบราว์เซอร์แล้วถามของจริง
รายการที่มันตัดสิน กับข้อที่มันตัดสินไม่ได้ อยู่ที่หัวไฟล์ของด่าน ไม่จดซ้ำที่นี่

พิสูจน์ว่าด่านยังจับของพังได้จริง สั่ง

    node tools/ด่านฟอนต์มากับเว็บ.mjs <ที่อยู่เว็บ> --ทดสอบตัวเอง
