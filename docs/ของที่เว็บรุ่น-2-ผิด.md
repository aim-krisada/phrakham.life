# ของที่เว็บรุ่น 2 ผิด — รายการสำหรับพี่เอม

ใบงาน [#30](https://aimgit.aimagin.com/v3/phrakham/-/issues/30) เขียน 30 ส.ค. 2569

เว็บ `phrakham.life` รุ่น 2 คือเว็บที่คนใช้อยู่ทุกวัน ใบนี้เทียบข้อมูลของเรากับของเขา
แล้วเจอสามเรื่องที่ผู้อ่านเห็นของไม่ครบหรือเห็นของเพี้ยน

ใบนี้ไม่แก้อะไรทั้งสิ้น แค่ทำรายการมาให้พี่เอมตัดสินว่าจะทำอย่างไรต่อ

เลขทุกตัวรันซ้ำได้ที่ [`tools/ใครถูก-เทียบรุ่น-2.py`](../tools/ใครถูก-เทียบรุ่น-2.py)
เหตุผลเต็ม ๆ อยู่ที่ [`ใครถูก-เราหรือรุ่น-2.md`](ใครถูก-เราหรือรุ่น-2.md)

## เรื่องที่ 1 — ฉบับ LSV ขาดหายไปสามเล่ม รวม 133 ข้อ

**ผู้อ่านเห็นอะไร** เปิด 1 ยอห์น 2 ยอห์น 3 ยอห์น แล้วช่องภาษาอังกฤษฉบับ LSV ว่างเปล่าทั้งสามเล่ม
1 ยอห์น 105 ข้อ 2 ยอห์น 13 ข้อ 3 ยอห์น 15 ข้อ

**ต้นเหตุ** ตารางแปลงชื่อเล่มในสคริปต์ของเขาเขียนรหัสสามเล่มนี้ว่า `1Jo` `2Jo` `3Jo`
แต่ไฟล์ต้นฉบับเรียกมันว่า `1Jn` `2Jn` `3Jn` ชื่อไม่ตรง บรรทัดจึงถูกทิ้งทั้งหมด
และไม่มีอะไรร้องเตือน เพราะโปรแกรมไม่ได้นับว่าควรได้กี่ข้อ

**หนักแค่ไหน** หนักที่สุดในสามเรื่อง เพราะเนื้อหายทั้งเล่ม ไม่ใช่แค่เพี้ยน

## เรื่องที่ 2 — คำว่า Selah หายไป 74 ข้อ

**ผู้อ่านเห็นอะไร** ในสดุดีกับฮาบากุก คำว่า `Selah` ท้ายข้อของฉบับ WEB หายไป
เช่น สดุดี 3.2 ของจริงจบด้วย `“There is no help for him in God.” Selah.`
บนเว็บรุ่น 2 เหลือแค่ `Many there are who say of my soul, “There is no help for him in God.`

**หนักแค่ไหน** สดุดี 71 ข้อ ฮาบากุก 3 ข้อ รวม 74 ข้อ

**ต้นเหตุ** ไม่ได้อยู่ที่สคริปต์ของรุ่น 2 แต่อยู่ที่ตัวกลางที่เขาโหลดมาใช้
คือที่เก็บ `TehShrike/world-english-bible` บน GitHub ซึ่งแปลงหน้าเว็บของ eBible เป็น JSON
ตอนแปลงมันทิ้งบรรทัด Selah ทิ้งไป ในไฟล์ JSON ทั้งชุดเหลือคำนี้อยู่คำเดียว

## เรื่องที่ 3 — ช่องว่างซ้อนตรงที่เชิงอรรถเคยอยู่ 85 ข้อ

**ผู้อ่านเห็นอะไร** ฉบับ WEB มีช่องว่างสองช่องกลางประโยค ตรงจุดที่ต้นฉบับมีเชิงอรรถ
เช่น 1 ซามูเอล 17.17 `“Now take for your brothers an ephah  of this parched grain`
และมีอีกหนึ่งข้อที่ช่องว่างไปอยู่หน้าจุด คือ โยบ 30.7 `under the nettles .`

**หนักแค่ไหน** เบาที่สุด เป็นเรื่องหน้าตา ไม่ใช่เนื้อหาย

**ต้นเหตุ** เหมือนเรื่องที่ 2 มาจากตัวกลางบน GitHub ที่ถอดเชิงอรรถออกแล้วทิ้งช่องว่างไว้

## เรื่องที่ไม่ใช่ความผิด แต่ควรรู้

ตัวบทฉบับ WEB ทั้งเล่มบนเว็บรุ่น 2 เป็นของ **14 มิถุนายน 2017**
ตั้งแต่นั้นเจ้าของเนื้อขัดเกลาสำนวนตัวเองจนออกเป็นฉบับตัวบทคงที่ปี 2020
ต่างกัน 5,897 ข้อ จาก 31,103 ข้อ

ไม่มีใครแปลงข้อมูลพลาด แต่คนอ่านเว็บรุ่น 2 อยู่ตอนนี้กำลังอ่านสำนวนเมื่อ 9 ปีก่อน

## ทางเลือกที่มี

หนึ่ง **ปล่อยไว้** ถ้าเว็บรุ่น 2 กำลังจะถูกแทนด้วยรุ่น 3 อยู่แล้ว การลงแรงแก้ของเก่าอาจไม่คุ้ม

สอง **แก้เฉพาะเรื่องที่ 1** เป็นการแก้จุดเดียวสามบรรทัดในตารางแปลงชื่อเล่ม แล้วสั่งแปลงใหม่
ได้เนื้อคืนมา 133 ข้อ เรื่องที่ 2 กับ 3 แก้ที่ตัวเราเองไม่ได้ ต้องเปลี่ยนต้นทาง

สาม **เปลี่ยนต้นทางของ WEB ทั้งชุด** ไปใช้ไฟล์ `eng-web_usfx` ของ eBible อย่างที่รุ่น 3 ใช้
แก้ได้ทั้งสามเรื่องพร้อมกัน และได้สำนวนปัจจุบันด้วย แต่ต้องเขียนตัวอ่านใหม่

**ผมไม่เสนอว่าควรเลือกข้อไหน** เพราะเรื่องนี้ขึ้นกับว่าเว็บรุ่น 2 จะอยู่ต่ออีกนานแค่ไหน ซึ่งพี่เอมรู้ดีกว่า
