# 18 · ถ้อยคำเชิงอรรถ (22 พ.ย. 2569)

ฉบับเต็ม ⇒ [G](18-ถ้อยคำเชิงอรรถ-รอบ1-G.md) · [N](18-ถ้อยคำเชิงอรรถ-รอบ1-N.md) ⇒ ลำดับ G เขียน → N ตรวจ → ผมตรวจกับของจริง → เสนอพี่เอม

## แผ่นเชิงอรรถ

| จุด | เดิม | G | N | ที่ใช้ |
| - | - | - | - | - |
| หัวแผ่น | เชิงอรรถของ TCV | เชิงอรรถจากผู้แปล TCV | เชิงอรรถฉบับ TCV | **เชิงอรรถฉบับ TCV** |
| ข้อที่ไม่มีเนื้อ | ก · ข้อ 21 | ตัด ก ⇒ เชิงอรรถข้อ 21 จากผู้แปล TCV | คง ก · ข้อ 21 คู่กับหัวแผ่น | **ก · ข้อ 21** + หัวแผ่นเดิม |
| ชื่อแผ่นที่โปรแกรมอ่านหน้าจออ่าน | เชิงอรรถ | เชิงอรรถ ก จากผู้แปล TCV | เชิงอรรถ ก ฉบับ TCV | **เชิงอรรถ ก ฉบับ TCV** · ข้อที่ไม่มีเนื้อ **เชิงอรรถข้อ 21 ฉบับ TCV** |

- G กับ N ทักตรงกันว่า *ของ TCV* อ่านแล้วเหมือน TCV เป็นชื่อคน ⇒ *ฉบับ* บอกว่าเป็นหนังสือ และสั้นกว่าของ G
- G เสนอตัด ก ในข้อที่ไม่มีเนื้อ เพราะคิดว่าหัวแผ่นไม่มีชื่อฉบับ ⇒ ที่จริงหัวแผ่นมีชื่อฉบับอยู่แล้วในแถวเดียวกัน ⇒ คง ก ไว้ให้คนตาดีรู้ว่าแตะตัวไหน
- ⚠️ N บอกว่าชื่อไทยของ TCV คือ *ฉบับอ่านเข้าใจง่าย* ⇒ **ไม่ใช้** ⇒ ยังไม่ได้ยืนยัน และถ้อยคำนี้ไม่ต้องใช้ชื่อเต็ม

## ย่อหน้าในหน้าแหล่งข้อมูล

- G เขียนว่า *ถ้ามีที่อยู่ข้ออื่นก็แตะไปอ่านข้อนั้นได้ทันที* ⇒ N ทักว่าอ่านแล้วเหมือน KJV ก็แตะได้ และเด็กอาจนึกว่า *ที่อยู่* คือที่อยู่บ้าน ⇒ N เสนอ *ถ้าคำอธิบายพูดถึงข้ออื่น คุณแตะไปอ่านข้อนั้นได้ทันที*
- ผมนับจากซองเชิงอรรถจริง ⇒ เชิงอรรถที่มีเลขข้อในเนื้อ TCV แตะได้ 540 จาก 661 · WEB 351 จาก 367 ⇒ *แตะได้ทันที* เกินจริง ⇒ ใช้ **ส่วนใหญ่แตะไปอ่านข้อนั้นได้**
  - ที่แตะไม่ได้ส่วนมากไม่ใช่ที่อยู่ข้ออื่น ⇒ TCV เป็นเลขข้อตามฉบับภาษาฮีบรู · WEB เป็นเวลา เช่น *3:00 p.m.*
- เปลี่ยน *คำอธิบาย* ของ N เป็น *เชิงอรรถ* ⇒ ประโยคแรกบอกแล้วว่าเชิงอรรถคืออะไร

## สวิตช์กรอบที่เล่าเรื่องเดียวกัน (บรรทัด r ใต้หัวข้อ)

- พี่เอมสั่งว่าสวิตช์ต้องแยกจากหัวข้อ ⇒ คำขึ้นต้น *แสดง* เข้าชุดกับ *แสดงเลขบท/ข้อ* และ *แสดงหัวข้อย่อย*
- G เสนอ *แสดงข้อเรื่องเดียวกัน* (แนะนำ) · *แสดงที่อยู่เรื่องเดียวกัน* · *แสดงข้อเทียบเรื่องเดียวกัน*
- N ค้านทั้งสาม ⇒ *ข้อ* ชวนให้นึกว่าจะเห็นเนื้อทั้งข้อ · *ที่อยู่* เด็กนึกถึงที่อยู่บ้าน ⇒ เสนอ *แสดงเรื่องเดียวกัน*
- ผมเห็นว่า *แสดงเรื่องเดียวกัน* ยังกำกวม อ่านได้ว่าจะเอาเรื่องมาแสดง ⇒ ใช้คำร่าง **แสดงที่เล่าเรื่องเดียวกัน** ⇒ บอกว่าจะเห็นว่าเล่าไว้ที่ไหน
- ⚠️ ยังรอพี่เอมอนุมัติ ⇒ ⚠️ N อ้างว่า TCV เรียกส่วนนี้ว่า *ข้อขนาน* ⇒ ยังไม่ได้ยืนยัน และไม่ได้ใช้
