## ⚠️ อ่านตรงนี้ก่อน

**นี่ ⛔ ไม่ใช่การปรึกษาผู้เชี่ยวชาญ** ⛔ ไม่มีการติดต่อ Nielsen Norman Group ⛔ ไม่มีมนุษย์คนไหนถูกถาม
เป็นการแตก **AI ตัวช่วยออกไปค้นเว็บ** หาเอกสารที่เผยแพร่ไว้มาอ้างอิง แล้วบางรอบลงมือวัดเองด้วย

⭐ **`nngroup.com` ถูกบล็อกจากเครื่องที่ทำงาน** ⇒ ข้ออ้างที่มาจากที่นั่นเป็น **ชื่อบทความ + ลิงก์ + ข้อความที่ผลค้นหายกมา** ⛔ ไม่ใช่การอ่านตัวเต็ม
⇒ **ทุกไฟล์มีหัวข้อ "แหล่งอ้างอิง" ที่แยกว่าอันไหน "ยืนยันแล้ว" อันไหน "ยังไม่ได้ยืนยัน" ⇒ ให้ดูตรงนั้นเสมอ**

**ของที่ยืนยันได้จริงมาจากการลงมือวัดเอง** เช่นรอบที่ 10 ที่เปิดเบราว์เซอร์จริงแล้ววัดเป็นพิกเซล
และตัวเลขขนาดพระคัมภีร์ที่โหลดของจริงมาบีบเอง
