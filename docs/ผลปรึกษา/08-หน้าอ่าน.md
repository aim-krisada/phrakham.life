# 1. หน้าอ่านรุ่นแรก

หน้าเดียว = หนึ่งบท (เช่น ยอห์น บทที่ 3) สร้างไว้ล่วงหน้าทุกบท ที่อยู่หน้าเว็บลงท้ายด้วยเลขข้อได้ เช่น `…/ยอห์น/3#ข้อ16`

## บนมือถือ (กว้าง 320–430 จุด) — ไล่จากบนลงล่าง

```
┌ แถบบน · ติดอยู่กับที่ · สูง 56 จุด ─────────────┐
│ พระคำ.ชีวิต   [ ยอห์น 3  ▾ ]            [ ☰ ]  │
└────────────────────────────────────────────────┘
   ยอห์น บทที่ 3                        ← หัวเรื่องใหญ่
   ฉบับ… (ชื่อฉบับแปล)                  ← เทาเล็ก บรรทัดเดียว

   แตะที่เลขข้อ เพื่อคัดลอก แชร์ หรือดูคำต้นฉบับ  [×]
                                        ← ขึ้นครั้งแรกครั้งเดียว ปิดแล้วจำ

   ขนาดตัวอักษร  [ ก– ] [ ก+ ]     [ ▶ ฟังเสียง ]
                                        ← แถวเดียว เลื่อนหายไปกับหน้า

   ๑ ในกาลเริ่มต้นนั้นพระวาทะทรงเป็นอยู่แล้ว ๒ พระ
   องค์ทรงอยู่กับพระเจ้า… ๓ …
   (ข้อความเรียงเป็นย่อหน้าเหมือนหนังสือ เลขข้อแทรกอยู่ในบรรทัด)

   ── จบบทที่ 3 ──
   [  ‹ ยอห์น 2  ]        [  ยอห์น 4 ›  ]      ← ปุ่มใหญ่ สูง 56 จุด
   [       เลือกหนังสือหรือบทอื่น       ]
   ข้อความลิขสิทธิ์ / ที่มาของฉบับแปล · เมนูอื่น ๆ ของเว็บ
```

**สิ่งที่ติดอยู่กับที่มีอย่างเดียว: แถบบน** สูง 56 จุด (ราว 8% ของจอ) มีของ 3 อย่างเท่านั้น

- `พระคำ.ชีวิต` กดกลับหน้าแรก (เหมือนหน้าหลัก)
- `ยอห์น 3 ▾` = **ชื่อบทเป็นปุ่มเปิดหน้าต่างเลือกหนังสือ** อันเดียวกับหน้าแรก บอกด้วยว่าตอนนี้อยู่ไหน ชื่อยาว ๆ อย่าง "เฉลยธรรมบัญญัติ 28" ตัดท้ายด้วยจุดสามจุด แต่ชื่อเต็มยังอยู่ให้เครื่องอ่านหน้าจอ
- `☰` เมนู เหมือนหน้าแรกทุกอย่าง

วัดที่ 320 จุดแล้ว: ชื่อเว็บ 80 + ปุ่มชื่อบท 110 + เมนู 44 + ระยะขอบและช่องไฟ 40 = 274 จุด พอดี เหลือที่ให้ปุ่มชื่อบทอีก 46 จุด
⚑ ถ้าคนขยายตัวอักษรของเบราว์เซอร์จนแถบบนสูงเกิน 20% ของจอ ให้ **เลิกตรึงแถบบน** ปล่อยให้เลื่อนหายไปเลย ไม่งั้นจอเล็ก ๆ จะไม่เหลือที่อ่าน

**เลขข้อ** ไม่ใช่ตัวยก (ตัวยกจะไปชนสระกับวรรณยุกต์ที่ลอยอยู่บนบรรทัดของไทย) แต่เป็น **ตัวเลขในบรรทัด ขนาด 0.72 เท่าของตัวอักษร สีเทาเข้ม หนา** เว้นช่องไฟบาง ๆ แล้วต่อด้วยข้อความ พื้นที่กดต้องไม่ต่ำกว่า 24×24 จุด (เพิ่มระยะขอบรอบตัวเลขให้ได้ขนาดนั้น)

**ย่อหน้า ไม่ใช่บรรทัดละข้อ** — คนที่ไม่เคยเข้าโบสถ์อ่านย่อหน้าแล้วรู้สึกเหมือนหนังสือปกติ ส่วนบรรทัดละข้อจะเหมือนตารางหรือกฎหมาย น่ากลัวและยาวขึ้นเป็นเท่าตัว (สดุดี 119 จะยาว 176 บรรทัด) ทุกข้อยังถูกห่อไว้แยกกันอยู่ดี จึงยังเน้นข้อ ลิงก์ถึงข้อ และอ่านออกเสียงทีละข้อได้

**ความกว้างบรรทัด** `min(34em, 44rem)` — ผูกกับขนาดตัวอักษร พอตัวใหญ่ขึ้นบรรทัดก็สั้นลงเอง
**ระยะห่างบรรทัด** 1.85 เท่า (ตัวใหญ่สุดลดเหลือ 1.75) ระยะห่างย่อหน้า 0.9 เท่า

## บนคอมพิวเตอร์

เหมือนกันทุกอย่าง ต่างแค่ 4 ข้อ

1. แถบบนเป็นแบบเดียวกับหน้าแรก: ชื่อเว็บซ้าย เมนู 5 อันขวา และ **ปุ่ม `ยอห์น 3 ▾` อยู่ตรงกลาง**
2. เนื้อความอยู่กลางจอ กว้างสุด 44rem (ราว 700 จุด) ที่เหลือเป็นขอบขาว
3. กดปุ่มลูกศร ← → บนคีย์บอร์ดเพื่อไปบทก่อน/บทถัดไป (มีบอกไว้ที่ท้ายบท)
4. หน้าต่างคำต้นฉบับโผล่เป็น **แผงด้านขวา** แทนที่จะเลื่อนขึ้นจากด้านล่าง

## ไปบทหน้า/บทก่อน และกลับไปเลือกใหม่

- **กลับไปเลือกใหม่**: ปุ่มชื่อบทบนแถบบน กดได้ตลอดเวลา ไม่ว่าจะเลื่อนไปไกลแค่ไหน
- **บทก่อน/บทถัดไป**: ปุ่มใหญ่สองปุ่มที่ **ท้ายบท** ที่เดียว (ทางเดินตามธรรมชาติ: อ่านจบแล้วไปต่อ) ไม่มีแถบล่างติดหน้าจอ ไม่มีลูกศรลอย
- **กฎเดียวจบ: บทถัดไป = บทถัดไปของทั้งเล่มพระคัมภีร์ ไม่ใช่แค่ในหนังสือเล่มนั้น** ยอห์น 21 → กิจการ 1, ยูดา → วิวรณ์ 1, 3 ยอห์น → ยูดา ⇒ **หนังสือที่มีบทเดียวอย่างยูดา ไม่ต้องเขียนโค้ดพิเศษเลย** และไม่มีปุ่มที่กดไม่ได้ให้เห็น
- สุดปลายทั้งสองข้าง: ปฐมกาล 1 ไม่มีปุ่มซ้าย · วิวรณ์ 22 ปุ่มขวาเปลี่ยนเป็น `กลับหน้าแรก`
- **สดุดี 119 (176 ข้อ)**: ไม่แบ่งหน้า ไม่ทยอยโหลด ตัวอักษรทั้งบทหนักแค่ไม่กี่สิบกิโลไบต์ ใส่ `content-visibility:auto` ที่ย่อหน้าให้เครื่องเก่าลื่นก็พอ
- **ท้ายบทเขียนว่า** `── จบบทที่ 3 ──` ให้รู้ว่าจบจริง ไม่ใช่โหลดไม่ครบ

## ถ้าเข้ามาที่ข้อใดข้อหนึ่ง (เช่น ยอห์น 3:16)

**เลื่อนไปหาข้อนั้น และเน้นข้อนั้นไว้ — ทั้งสองอย่าง**

- เลื่อนไปให้ข้อนั้นอยู่ **ประมาณ 1 ใน 3 จากขอบบน** ไม่ใช่ชิดขอบบนสุด จะได้เห็นข้อความก่อนหน้าด้วยว่ามาจากบริบทอะไร (และแถบบนที่ตรึงไว้จะไม่บังพอดี)
- ไม่ทำเป็นภาพเลื่อนไหล ให้ไปโผล่เลย คนสูงอายุเห็นหน้าไหลเองแล้วตกใจ
- **การเน้น**: พื้นเหลืองอ่อน **บวกแถบทึบหนา 4 จุดที่ขอบซ้าย** (ต้องไม่ใช้สีอย่างเดียว) และมีข้อความให้เครื่องอ่านหน้าจอบอกว่า "พาคุณมาที่ ข้อ 16"
- มีบรรทัดเล็ก ๆ เหนือข้อความว่า `พาคุณมาที่ข้อ 16 · [ อ่านตั้งแต่ต้นบท ]`
- **การเน้นค้างไว้ ไม่จางหายเอง** และหายเมื่อกดบทถัดไป/เลือกบทใหม่

**เรื่องการส่งลิงก์ต่อ**: ที่อยู่หน้าเว็บลงท้ายด้วย `#ข้อ16` อยู่แล้ว ⇒ เพื่อนที่รับลิงก์ไปเปิด **จะเห็นเหมือนกันเป๊ะ** คือถูกพาไปที่ข้อ 16 และเห็นข้อ 16 ถูกเน้น นี่คือสิ่งที่คนส่งตั้งใจพอดี การเน้นจึงเป็นข้อดี ไม่ใช่ข้อเสีย เพียงแต่ต้องเน้นแบบ "นี่คือข้อที่คุณตามมา" ไม่ใช่แบบ "ข้อนี้สำคัญกว่าข้ออื่น" — สีอ่อน ๆ พอเห็น ไม่ใช่ปากกาเน้นข้อความสีจัด และต้องอ่านตัวหนังสือบนพื้นสีนั้นได้ชัดเท่าเดิม

## การส่งต่อ (Line / Facebook)

ไม่เพิ่มปุ่มอะไรบนหน้าเลย ใช้ทางเดียวกับคำต้นฉบับ คือ **แตะที่เลขข้อ**

```
┌ แผ่นเลื่อนขึ้นจากด้านล่าง ───────────────┐
│ ยอห์น 3:16                        [ × ] │
│ "เพราะว่าพระเจ้าทรงรักโลก จนได้…"        │
│ [ คัดลอกข้อความ ] [ ส่งต่อ ]             │
│ ─────────────────────────────────────── │
│ คำต้นฉบับ                                │
│ …                                        │
└─────────────────────────────────────────┘
```

- **คัดลอกข้อความ** ได้ก้อนพร้อมวาง: ข้อความ + `ยอห์น 3:16 · พระคำ.ชีวิต` + ที่อยู่หน้าเว็บ
- **ส่งต่อ** เรียกแผงแชร์ของเครื่อง (Line, Facebook, ข้อความ) ⇒ โผล่เฉพาะเครื่องที่ทำได้ (มือถือเกือบทั้งหมด) เครื่องที่ทำไม่ได้ก็ไม่ต้องเห็นปุ่มนี้ เหลือปุ่มคัดลอกอย่างเดียว
- **สิ่งที่คุ้มที่สุดคือสิ่งที่มองไม่เห็น**: ใส่ข้อมูลตัวอย่างลิงก์ (og:title / og:description) ของทุกบทไว้ล่วงหน้า พอวางลิงก์ใน Line จะขึ้นเป็นการ์ด "ยอห์น บทที่ 3 — พระคำ.ชีวิต" พร้อมข้อความสองสามบรรทัด แทนที่จะเป็นตัวหนังสือเปล่า ๆ ⛔ ไม่ต้องมีปุ่มอะไรเพิ่มบนหน้า

# 2. ขนาดตัวอักษร

**อยู่ตรงไหน** แถวเดียวใต้หัวเรื่อง เลื่อนหายไปกับหน้า ไม่ตรึงไว้ เพราะเป็นสิ่งที่คนตั้งครั้งเดียวแล้วไม่ยุ่งอีก (ตั้งแล้วจำไว้)

**หน้าตา** — ปุ่มสองปุ่มโต ๆ ไม่มีแถบเลื่อน (แถบเลื่อนยากสำหรับมือที่สั่น)

```
ขนาดตัวอักษร   [  ก–  ]  [  ก+  ]   ระดับ 3 จาก 5
```

- ป้ายกำกับไทยจริง: **`ขนาดตัวอักษร`**
- ปุ่ม: `ก–` (ชื่อสำหรับเครื่องอ่านหน้าจอ = `ตัวอักษรเล็กลง`) และ `ก+` (= `ตัวอักษรใหญ่ขึ้น`) แต่ละปุ่มไม่ต่ำกว่า 44×44 จุด
- ข้อความบอกระดับ `ระดับ 3 จาก 5` เปลี่ยนแล้วประกาศให้เครื่องอ่านหน้าจอทราบ
- ถึงระดับสุดท้ายแล้วปุ่มนั้นกดไม่ได้ (ยังเห็นอยู่ ไม่หายไป)

**ขนาดจริง 5 ระดับ** (เทียบกับค่าปกติของเบราว์เซอร์ 16 จุด)

| ระดับ | ขนาด | ระยะห่างบรรทัด |
|---|---|---|
| 1 | 1.00 เท่า = 16 จุด | 1.9 |
| 2 | 1.125 เท่า = 18 จุด | 1.9 |
| **3 (ค่าเริ่มต้น)** | **1.25 เท่า = 20 จุด** | **1.85** |
| 4 | 1.5 เท่า = 24 จุด | 1.75 |
| 5 | 1.75 เท่า = 28 จุด | 1.75 |

**ทำไม 20 จุดเป็นค่าเริ่มต้น** เว็บทั่วไปใช้ 16 จุด แต่หน้านี้มีงานเดียวคืออ่านยาว ๆ และคนอ่านส่วนใหญ่อายุมาก 20 จุดคือขนาดที่คนส่วนใหญ่ไม่ต้องแตะปุ่มเลย ⇒ ปุ่มกลายเป็นของสำรอง ไม่ใช่ของบังคับ

**⛔ ห้ามไปทับการตั้งค่าของเบราว์เซอร์** หน้าหลักตั้ง `html{font-size:100%}` ไว้แล้ว ต้องคงไว้ **ปุ่มนี้เป็นตัวคูณ ไม่ใช่ตัวกำหนดขนาดตายตัว** — เขียนเป็น `font-size: calc(1rem × ตัวคูณ)` เท่านั้น ⇒ ผู้สูงอายุที่ตั้ง "ตัวอักษรใหญ่" ไว้ในเบราว์เซอร์อยู่แล้ว จะได้ใหญ่ของเขา **คูณ** ใหญ่ของเรา ไม่ใช่ถูกรีเซ็ต และห้ามใส่ `user-scalable=no` หรือ `text-size-adjust:none`

**การจำค่า**
เก็บใน `localStorage` ชื่อ `pk.text` เก็บแค่ตัวเลข 1–5

- **ต้องใส่สคริปต์สั้น ๆ ใน `<head>` ให้ตั้งขนาดก่อนหน้าจะวาดครั้งแรก** ไม่งั้นหน้าจะกระพริบจากตัวเล็กเป็นตัวใหญ่ทุกครั้งที่เปิด (เพราะเว็บนี้สร้างหน้าไว้ล่วงหน้า)
- ตรวจค่าที่อ่านได้ทุกครั้ง: ต้องเป็นจำนวนเต็ม 1–5 ไม่งั้นใช้ 3

**อาการเสียและสิ่งที่คนอ่านเห็น — คำตอบสั้น ๆ คือ "ไม่เห็นอะไรเลย"**

| อาการ | เกิดอะไร | คนอ่านเห็นอะไร |
|---|---|---|
| Safari โหมดส่วนตัว | อ่านค่าได้ แต่พอเขียนจะโยนข้อผิดพลาดทันที | ปุ่มยัง**ทำงานปกติ**ในรอบนี้ (เก็บค่าไว้ในตัวแปรธรรมดา) แค่คราวหน้ากลับมาเป็นค่าเดิม · ⛔ ไม่ขึ้นคำเตือน |
| iOS ลบข้อมูลเว็บที่ไม่ได้เข้าเกิน 7 วัน | ค่าหาย | กลับมาเป็นระดับ 3 · ⛔ ไม่ขึ้นคำเตือน กดใหม่ 2 ที |
| ปิดคุกกี้/ที่เก็บข้อมูลทั้งหมด | แม้แต่การอ่านค่าก็โยนข้อผิดพลาด | เริ่มที่ระดับ 3 ปุ่มยังใช้ได้ทั้งหน้า |
| มือถือเครื่องเดียวทั้งบ้าน | ลูกตั้งเล็ก แม่มาเจอตัวเล็ก | กดปุ่มเองได้ทันที ไม่ต้องเข้าเมนู |

⚑ กฎเดียวกับที่หน้าหลักวางไว้แล้ว: **เขียนไม่ได้ = ทำเหมือนไม่เคยจำอะไร ⛔ ห้ามขึ้นข้อความเตือนให้คนอ่านเห็น** การขึ้นข้อความว่า "เบราว์เซอร์ของคุณจำค่าไม่ได้" ทำให้คนแก่กลัวว่าเครื่องพัง ทั้งที่หน้าเว็บใช้ได้ครบ

## ขนาดตัวอักษรอย่างเดียวพอไหม — ตอบตรง ๆ ว่า **ไม่พอ**

ระยะห่างบรรทัดสำคัญพอ ๆ กัน และสำคัญกับ**ภาษาไทยมากกว่าภาษาอังกฤษ** เพราะไทยมีสระกับวรรณยุกต์ซ้อนกันขึ้นไปข้างบน (เช่น "เปื้อน" "ที่" "ญั") และมีสระใต้บรรทัด (ุ ู) ⇒ ตัวหนังสือกินที่แนวตั้งมากกว่าอังกฤษ ถ้าบรรทัดชิดกัน วรรณยุกต์ของบรรทัดล่างจะไปเบียดสระใต้ของบรรทัดบน สายตาแยกไม่ออกว่าอยู่บรรทัดไหน ปัญหานี้จะ**หนักขึ้น**เมื่อขยายตัวอักษร ถ้าไม่ขยายระยะบรรทัดตาม

ความกว้างบรรทัดก็เหมือนกัน ยิ่งตัวใหญ่ ยิ่งต้องบรรทัดสั้นลง ไม่งั้นตาหาบรรทัดถัดไปไม่เจอ

**ข้อสรุป: ปุ่มเดียวที่ขยับสามอย่างพร้อมกัน ดีกว่าสามปุ่มแยกกัน**
`ก+` หนึ่งครั้ง = ตัวอักษรใหญ่ขึ้น + ระยะบรรทัดปรับตาม + บรรทัดสั้นลงเอง คนอ่านไม่ต้องรู้เรื่องพวกนี้เลย เห็นแค่ "อ่านสบายขึ้น" ⛔ ไม่ต้องมีปุ่ม "ระยะห่างบรรทัด" แยกออกมาให้รก (ระยะบรรทัดต้องไม่ต่ำกว่า 1.5 เท่าในทุกระดับ ตามข้อกำหนดการเข้าถึง)

# 3. อ่านออกเสียง

## งานวิจัยบอกว่าอะไร

**ข่าวดี: ทั้งสามค่ายใหญ่มีเสียงไทยติดเครื่องมาให้อยู่แล้ว** (จากฐานข้อมูลเสียงของโครงการ Readium Speech ซึ่งเป็นโครงการที่ไล่ทดสอบเสียงจริงทีละเครื่อง)

| แพลตฟอร์ม | เสียงไทย | ติดมากับเครื่องเลยไหม |
|---|---|---|
| iPhone / iPad / Mac | **Kanya** (th-TH) | **ใช่** (Narisa ต้องโหลดเพิ่ม) |
| Android / ChromeOS | **Google ไทย** (th-TH) | **ใช่** — แต่ดูข้อควรระวังข้างล่าง |
| Windows | **Microsoft Pattara** (th-TH) | ใช่ ถ้าเครื่องลงชุดภาษาไทยไว้ |
| Edge บนคอมพิวเตอร์ | Premwadee / Niwat (คุณภาพสูงมาก) | ใช่ แต่**ต้องต่อเน็ต** |
| Linux เดสก์ท็อป | มีแต่ eSpeak | มี แต่คุณภาพต่ำมาก โครงการเดียวกันบอกว่า "ควรเลี่ยงให้หมด" |

**ข่าวร้าย และเป็นข่าวร้ายที่ตรงกับคนไทยส่วนใหญ่พอดี**

1. **Chrome บน Android โกหก** — รายชื่อเสียงที่มันคืนกลับมาไม่ใช่รายชื่อเสียงที่มีจริงในเครื่อง แต่เป็นรายชื่อ "ภาษาทั้งหมดที่รองรับ" ⇒ th-TH โผล่ในรายชื่อทั้งที่ยังไม่ได้โหลดชุดเสียง **และถ้าเลือกไป Chrome จะเปลี่ยนไปใช้เสียงอังกฤษอ่านข้อความไทยเงียบ ๆ** ⇒ **การตรวจด้วย getVoices() อย่างเดียวเชื่อไม่ได้ บนเครื่องที่คนไทยใช้มากที่สุด**
2. **iPhone: เปิดหน้าจอค้างไว้เท่านั้น** พอปิดจอหรือสลับไปแอปอื่นระหว่างที่กำลังอ่าน เสียงจะหยุด และบางกรณีต้องรีโหลดหน้าถึงจะกลับมาอ่านได้อีก
3. **Safari** ไม่แสดงเสียงที่โหลดเพิ่ม และแย่กว่านั้นคือ ถ้าคนโหลดเสียงคุณภาพสูงของภาษาเดียวกันมาลง เสียงเดิม**หายไปจากรายชื่อ**ทั้งภาษา
4. **Chrome บนคอมพิวเตอร์** มีบั๊กที่ประโยคยาวเกิน ~14 วินาทีจะหยุดกลางคัน และไม่บอกตำแหน่งคำที่กำลังอ่าน
5. **ไม่ได้ยืนยัน**: ไม่พบตัวเลขจริงว่าคนไทยกี่เปอร์เซ็นต์มีเสียงไทยพร้อมใช้ในเครื่อง ผมเดาว่าสูง (เพราะคนไทยส่วนใหญ่ตั้งเครื่องเป็นภาษาไทย และ Android โหลดเสียงของภาษาระบบมาให้) แต่**เดา**

## แบบที่ออกให้ — ตั้งใจให้พังแบบเงียบ ๆ

**ผมเห็นด้วยกับพี่เอม: ไม่มีเสียงไทย = ซ่อนปุ่มไปเลย ⛔ ไม่ทำเป็นปุ่มสีเทากดไม่ได้**

เหตุผล: คำอธิบายที่ซื่อสัตย์ต้องเขียนว่า "เข้าตั้งค่า → การช่วยการเข้าถึง → เนื้อหาที่อ่านออกเสียง → เสียงพูด → ไทย → ดาวน์โหลด" คนอ่านกลุ่มนี้จะไม่ทำ 6 ขั้นนี้ และปุ่มเทา ๆ ที่กดไม่ได้คือ "ความล้มเหลวถาวร" ที่ค้างอยู่บนหน้าที่มีงานเดียวคือให้อ่าน — ทุกครั้งที่เปิดหน้าใหม่ก็เจออีก
**แต่**เพิ่มอีกนิดเดียว: เขียนคำอธิบายไว้ที่หน้า "เกี่ยวกับเรา" หัวข้อ *"ทำไมเครื่องผมไม่มีปุ่มฟังเสียง"* ⇒ คนที่สงสัยมีที่ให้ค้นเจอ โดยไม่ต้องเอาความล้มเหลวไปแขวนไว้กลางหน้าอ่าน

**การตรวจสองชั้น** (เพราะชั้นเดียวไม่พอ ตามข้อ 1 ข้างบน)

- **ชั้นที่ 1 ก่อนแสดงปุ่ม**: หาเสียงที่ `lang` ขึ้นต้นด้วย `th` (ระวัง Android เขียน `th_TH` และ Firefox Android เขียนแปลก ๆ) → ตัดเสียง eSpeak ทิ้ง → ถ้าไม่เจอเลย **ไม่แสดงปุ่ม จบ ไม่บอกอะไร**
- **ชั้นที่ 2 ตอนกดครั้งแรกของเครื่องนี้**: ลองอ่านข้อ 1 แล้วจับเวลา ถ้า (ก) เกิดข้อผิดพลาด หรือ (ข) 2 วินาทีแล้วยังไม่เริ่ม หรือ (ค) อ่านจบเร็วผิดปกติ (ต่ำกว่า 35% ของเวลาที่ควรใช้ = สัญญาณว่ามันเปลี่ยนไปใช้เสียงอังกฤษ) ⇒ หยุด, จำไว้ว่าเครื่องนี้ใช้ไม่ได้, **ซ่อนปุ่มถาวร** และขึ้นข้อความสั้น ๆ ครั้งเดียว: **"เครื่องนี้ยังอ่านภาษาไทยไม่ได้ ขออภัยครับ"**

⇒ ความล้มเหลวเกิดแค่ครั้งเดียวในชีวิตของเครื่องนั้น หลังจากนั้นหน้าตาเหมือนไม่เคยมีปุ่มนี้

## ตัวปุ่มและสถานะ

**ยังไม่เล่น** — อยู่ในแถวเดียวกับขนาดตัวอักษร: `[ ▶ ฟังเสียง ]`

**กำลังเล่น** — มีแถบล่างติดหน้าจอโผล่ขึ้นมา **เฉพาะตอนเล่นเท่านั้น** สูง 56 จุด

```
┌──────────────────────────────────────────────────┐
│ กำลังอ่าน ข้อ 16   [ ⏸ หยุดชั่วคราว ] [ ⏹ หยุด ] │
└──────────────────────────────────────────────────┘
   ปิดหน้าจอแล้วเสียงจะหยุด        ← เทาเล็ก ขึ้นครั้งแรกครั้งเดียว
```

- `หยุดชั่วคราว` กดแล้วเปลี่ยนเป็น `เล่นต่อ` (เปลี่ยนคำจริง ๆ ไม่ใช้ไอคอนอย่างเดียว)
- `หยุด` = เลิก กลับสู่สภาพเดิม แถบล่างหายไป

**อ่านทีละอะไร: ทีละข้อ** ส่งให้เครื่องอ่านทีละข้อแล้วต่อคิว เหตุผล 4 ข้อ — (ก) เลี่ยงบั๊ก 14 วินาทีของ Chrome (ข) ได้ตำแหน่ง "ตอนนี้อ่านข้อไหน" ฟรี โดยไม่ต้องพึ่งสัญญาณบอกตำแหน่งคำ ซึ่งเสียง Google ไม่ส่งมา (ค) สั่ง "อ่านจากข้อนี้" ได้ทันที (ง) หยุดแล้วเล่นต่อจะเริ่มตรงหัวข้อพอดี ไม่ค้างกลางประโยค
ข้อที่ยาวเกิน ~180 ตัวอักษร ให้ตัดต่อที่**ช่องว่าง**ในข้อความไทย (ไทยเว้นวรรคที่จบวลี) แล้วส่งเป็นท่อน ๆ

**เริ่มอ่านจากไหน** — ถ้าเข้ามาที่ข้อ 16 ก็เริ่มที่ข้อ 16 ถ้าเข้ามาทั้งบทก็เริ่มข้อ 1 และในแผ่นของแต่ละข้อมีปุ่ม `▶ ฟังจากข้อนี้` แถบล่างบอกตลอดว่า `กำลังอ่าน ข้อ N` จึงไม่มีทางงง

**เน้นข้อที่กำลังอ่าน: เน้น** ใช้หน้าตาเดียวกับการเน้นข้อที่ตามลิงก์มา (พื้นอ่อน + แถบซ้าย) จะได้มีภาษาภาพเดียวในหน้านี้ ⛔ **ไม่เน้นทีละคำ** เพราะเสียงส่วนใหญ่ไม่ส่งสัญญาณบอกคำมา และภาษาไทยไม่มีช่องว่างระหว่างคำ จะเน้นผิดตำแหน่ง

**ถ้าคนเลื่อนหนีไปเอง** — หน้าเลื่อนตามข้อที่อ่านอยู่โดยอัตโนมัติ **แต่หยุดตามทันทีที่คนเลื่อนเอง** แล้วขึ้นปุ่มเล็กในแถบล่างว่า `กลับไปที่ข้อที่อ่านอยู่` ⛔ ห้ามแย่งการเลื่อนกับคนอ่านเด็ดขาด (และถ้าเครื่องตั้ง "ลดการเคลื่อนไหว" ให้กระโดดไปเลย ไม่ต้องไหล)

**เปลี่ยนบท / กลับหน้าแรก / ปิดหน้า** — หยุดเสียงทันทีทุกกรณี v1 **ไม่อ่านต่อข้ามบท** อ่านจบบทแล้วหยุด แล้วบอกว่า "อ่านจบบทแล้ว"

**ปิดหน้าจอ / สลับไปแอปอื่น** — พอหน้าถูกซ่อน ให้สั่งหยุดชั่วคราวทันที กลับมาแล้ว **ไม่เล่นต่อเอง** ให้คนกด `เล่นต่อ` เอง (iPhone บังคับให้ต้องมีการกดอยู่แล้ว) ถ้ากดเล่นต่อแล้ว 2 วินาทียังไม่มีเสียง ให้ยกเลิกแล้วเริ่มอ่านข้อนั้นใหม่ตั้งแต่ต้น และบอกไว้ตรง ๆ ครั้งเดียวใต้แถบล่างว่า **"ปิดหน้าจอแล้วเสียงจะหยุด"**

## อยู่กับเครื่องอ่านหน้าจออย่างไร

คนที่ใช้เครื่องอ่านหน้าจอ **มีเสียงอยู่แล้ว** ปุ่มนี้ไม่ใช่ของช่วยเขา มันคือของสำหรับคนตาดีที่อยากฟัง ถ้าออกแบบพลาด เสียงสองทางจะทับกันจนใช้ไม่ได้เลย

1. **⛔ ห้ามเริ่มอ่านเอง** ไม่ว่ากรณีใด ต้องกดปุ่มเท่านั้น
2. **⛔ ห้ามซ่อนปุ่มจากเครื่องอ่านหน้าจอ** เขาอาจอยากใช้จริง ๆ (เช่น คนสายตาเลือนราง ที่ชอบเสียงธรรมชาติมากกว่าเสียงเครื่องอ่านของตัวเอง) ⇒ ตั้งชื่อปุ่มให้ชัด: `ฟังเสียงอ่านทั้งบท`
3. **⛔ ห้ามประกาศทุกข้อที่อ่าน** ข้อความ `กำลังอ่าน ข้อ 16` ต้อง**ไม่**เป็นข้อความประกาศอัตโนมัติ ไม่งั้นเครื่องอ่านหน้าจอจะอ่านข้อ 16 ซ้ำแข่งกับเสียงที่กำลังอ่านข้อ 16 อยู่ ⇒ ประกาศเฉพาะการเปลี่ยนสถานะใหญ่ ๆ อย่างละครั้ง: `เริ่มอ่าน` / `หยุดแล้ว` / `อ่านจบบทแล้ว`
4. **⛔ ห้ามย้ายตำแหน่งโฟกัส**ไปตามข้อที่กำลังอ่าน การเลื่อนหน้าตามเป็นเรื่องของสายตาเท่านั้น
5. การเน้นข้อที่กำลังอ่าน ใช้แค่สีกับแถบ ⛔ ไม่ต้องใส่ป้ายบอกสถานะให้เครื่องอ่านหน้าจอ

## v1 หรือ v2 — ตอบตรง ๆ

**ผมแนะนำ v2 ครับ** ไม่ใช่เพราะไม่มีเสียงไทย (มี และมีติดเครื่องมาด้วย) แต่เพราะ

- จุดที่พังคือ **Chrome บน Android** ซึ่งคือคนไทยส่วนใหญ่ และมันพังแบบ**เงียบ** คือเปลี่ยนไปอ่านด้วยเสียงอังกฤษ ต้องเขียนโค้ดจับเวลาไล่ตรวจถึงจะรู้
- บน iPhone เสียงหยุดเมื่อปิดจอ ซึ่งเป็นสิ่งที่คนฟังพระคัมภีร์ทำเป็นปกติ
- ของชิ้นนี้ชิ้นเดียว มีสถานะและกรณีพิเศษมากกว่าทั้งหน้ารวมกัน ซึ่งตรงข้ามกับ KISS
- ยังไม่มีใครฟังเสียงไทยฟรีอ่านพระคัมภีร์ยาว ๆ แล้วบอกได้ว่าฟังรู้เรื่องแค่ไหน — ต้องลองฟังจริงก่อน

**แต่ถ้าพี่เอมจะทำใน v1 ก็ทำได้ปลอดภัย** เพราะแบบที่ออกให้ข้างบนนี้ **พังแล้วปุ่มหายไปเอง** ⇒ กรณีเลวร้ายที่สุดคือหน้ากลายเป็น "v1 ที่ไม่มีปุ่มฟังเสียง" ซึ่งคือสิ่งที่ผมแนะนำอยู่แล้วพอดี ขอแค่ทำเป็นสวิตช์เปิด/ปิดได้ที่เดียว และ**ลองฟังด้วยหูจริงบน Android หนึ่งเครื่อง iPhone หนึ่งเครื่องก่อนเปิดให้คนทั่วไป**

**v1 ใช้ทางเดียวกับการแชร์ ไม่เพิ่มอะไรบนหน้าเลย: แตะที่เลขข้อ**

- **มือถือ**: แผ่นเลื่อนขึ้นจากด้านล่าง สูงไม่เกิน 85% ของจอ
- **คอมพิวเตอร์**: แผงด้านขวา กว้าง 360 จุด

ข้างในเรียงลงมา: ชื่อข้อ (`ยอห์น 3:16`) → ข้อความข้อนั้น → `[ คัดลอกข้อความ ] [ ส่งต่อ ] [ ▶ ฟังจากข้อนี้ ]` → หัวข้อ **`คำต้นฉบับ`** → รายการคำเรียงตามลำดับต้นฉบับ แต่ละแถวมี 3 อย่าง: **คำไทย · คำต้นฉบับ (กรีก/ฮีบรู) · คำอ่านเป็นตัวอักษรไทย** และคำแปลสั้น ๆ อีกบรรทัด

**ปิดอย่างไร**: ปุ่ม `×` มุมขวาบน · แตะพื้นที่มืดนอกแผ่น · ปุ่ม Esc · ปัดลง (มือถือ) ⇒ ปิดแล้วโฟกัสกลับไปที่เลขข้อเดิม ระหว่างเปิดอยู่ ของข้างหลังกดไม่ได้จริง (ใช้กติกาเดียวกับหน้าต่างเลือกหนังสือของหน้าหลัก)

**ให้คนเจออย่างน้อยหนึ่งครั้ง** — บรรทัดเดียวใต้หัวเรื่อง ขึ้นเฉพาะการเข้าครั้งแรกและปิดแล้วจำ: **"แตะที่เลขข้อ เพื่อคัดลอก แชร์ หรือดูคำต้นฉบับ"** บวกกับที่หน้าแรกสัญญาไว้แล้วว่า "เทียบคำต้นฉบับได้ทุกคำ"

**ทำไมไม่ให้แตะที่ตัวคำในเนื้อความ (ซึ่งคือสิ่งที่สัญญาไว้ตรงตัว)** — เพราะภาษาไทยไม่มีช่องว่างระหว่างคำ ต้องตัดคำเอง ตัดพลาดเมื่อไหร่คนแตะแล้วได้คำผิด และเนื้อความจะเต็มไปด้วยจุดที่กดได้ ทำให้เลื่อนหน้าธรรมดายังลำบาก **v1 จึงให้แตะที่เลขข้อ แล้วเห็นคำทั้งข้อเรียงให้ครบทุกคำ** ซึ่งก็คือ "ทุกคำ" ตามที่สัญญา ส่วน "แตะคำในเนื้อความแล้วกระโดดไปที่คำนั้น" เก็บไว้ v2

ข้อมูลคำต้นฉบับเก็บเป็นไฟล์แยกรายบท **โหลดตอนเปิดแผ่นครั้งแรกเท่านั้น** ⇒ คนที่ไม่เคยใช้ไม่ต้องโหลดอะไรเพิ่มเลย

# 6. ค่อยทำทีหลังได้

ตั้งใจไม่ใส่ใน v1 ทั้งหมดนี้ครับ

1. **ปุ่มฟังเสียง** (ถ้าพี่เอมเห็นด้วยกับข้อ 3) — เป็นของชิ้นแรกของ v2
2. **แตะที่คำในเนื้อความ** เพื่อดูคำต้นฉบับคำนั้นโดยตรง (v1 ให้แตะเลขข้อแล้วเห็นทั้งข้อ)
3. **จำว่าอ่านค้างไว้ตรงไหน** แล้วพากลับมาที่เดิม (v1 จำแค่ระดับบท ตามที่ตกลงไว้แล้ว)
4. **ปุ่ม "ขึ้นบนสุด"** ตอนอ่านบทยาว ๆ (แถบบนมีปุ่มเลือกบทให้อยู่แล้ว น่าจะพอ)
5. **ปัดซ้ายขวาเพื่อเปลี่ยนบท** และ **เลื่อนยาวข้ามบทไม่มีรอยต่อ** — เสี่ยงกับคนสูงอายุที่นิ้วปัดไม่แม่น และทำให้ที่อยู่หน้าเว็บกับสิ่งที่เห็นไม่ตรงกัน
6. **โหมดกลางคืน / เปลี่ยนสีพื้น** — ของถูกและช่วยเยอะ แต่เพิ่มปุ่มอีกปุ่ม (ทางลัดที่แทบไม่มีต้นทุน: ทำให้หน้าเปลี่ยนสีตามที่เครื่องตั้งไว้เอง โดย**ไม่ต้องมีปุ่ม** — ถ้าพี่เอมอยากได้ ใส่ใน v1 ได้เลย)
7. **หัวข้อย่อย เชิงอรรถ ข้ออ้างอิงไขว้** ในเนื้อความ
8. **อ่านเทียบสองฉบับพร้อมกัน**
9. **ทำข้อเป็นรูปภาพสวย ๆ ไว้แชร์** แบบที่แอปดัง ๆ มี
10. **ที่คั่นหน้า / ขีดเส้นใต้ / โน้ตส่วนตัว** — ต้องมีที่เก็บและมีความเป็นเจ้าของ ขัดกับ "ไม่มีบัญชีผู้ใช้"
11. **ใช้งานตอนไม่มีเน็ต (PWA)**
12. **ปุ่มขนาดตัวอักษรย้ายขึ้นไปอยู่บนแถบบน** ถ้าลองให้คนใช้จริงแล้วพบว่าหาไม่เจอ

# 7. ที่ต้องให้เจ้าของตัดสิน

1. **ที่อยู่ของหน้า** จะเป็นภาษาไทย `พระคำ.ชีวิต/ยอห์น/3` (อ่านเข้าใจทันที แต่เวลาคัดลอกไปวางใน Line อาจกลายเป็นตัวอักษรประหลาดยาว ๆ) หรือเป็นตัวย่อภาษาอังกฤษ `พระคำ.ชีวิต/jhn/3` (สั้น ไม่เพี้ยน แต่คนอ่านไม่รู้ว่าแปลว่าอะไร)
2. **การจัดข้อความ** จะเรียงเป็น**ย่อหน้าเหมือนหนังสือ** โดยมีเลขข้อแทรกในบรรทัด (ผมแนะนำอันนี้) หรือ**ขึ้นบรรทัดใหม่ทุกข้อ** แบบพระคัมภีร์เล่มเดิม
3. **ปุ่มฟังเสียง** จะทำใน**รุ่นแรกเลย** หรือ**เก็บไว้รุ่นถัดไป** (ผมแนะนำรุ่นถัดไป และให้ลองฟังเสียงไทยจริงบน Android กับ iPhone อย่างละเครื่องก่อนตัดสิน)
4. **ขนาดตัวอักษรเริ่มต้น** จะเอา **20 จุด** (ใหญ่กว่าเว็บทั่วไป คนสูงอายุส่วนใหญ่ไม่ต้องแตะปุ่มเลย — ผมแนะนำอันนี้) หรือ **18 จุด** (ดูเป็นทางการกว่า แต่คนสูงอายุต้องกดขยายเอง)
