## Description

**As a** คนที่เดินแสวงหาพระธรรมตอนเช้า

**I want to** เลือกข้อที่อยากฟัง **ข้ามบทข้ามเล่มได้** แล้วกดปุ่มเดียวให้มันอ่านให้ฟัง

**So that** ฟังพระคำระหว่างเดินได้ **โดยไม่ต้องมองจอ ไม่ต้องหยิบมือถือออกจากกระเป๋า**

⇒ **คำของพี่เอม 22 ต.ค. 2569** ⇒ *"ตอนเช้าเวลาเดินแสวงหาพระธรรม ผมอยากจะกดเล่นข้อพระคำที่ผมเลือกได้"*

🔴 **เรื่องนี้ ⛔ ไม่เกี่ยวกับการวางหลายคอลัมน์ของ us07** ⇒ **พี่เอมสั่งเองว่าห้ามปนกัน** ⇒ ⛔ **ห้ามเอาตัวเลือกของสองเรื่องนี้มารวมเป็นชุดเดียวกัน**

## Acceptance criteria

* 🔴 **เสียงต้องเล่นต่อได้ตอนจอดับและมือถืออยู่ในกระเป๋า** ⇒ **นี่คือข้อที่ตัดสินทั้งใบ**
  ⇒ ⭐ **นี่คือเหตุผลที่เว็บรุ่น 2 เลือกทำเป็นไฟล์เสียงสำเร็จรูป ⛔ ไม่ใช่ให้เครื่องอ่านสด** ⇒ เขาเขียนไว้เองที่หัวไฟล์ `etl/gen_audio.py`
  ⇒ **ต้องพิสูจน์บนมือถือจริง ⛔ ไม่ใช่จอจำลอง** ⇒ **ทำไม่ได้ให้รายงาน ⛔ อย่าเงียบ**
