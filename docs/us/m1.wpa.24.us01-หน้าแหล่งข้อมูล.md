## Description

**As a** คริสเตียนไทยที่อ่านพระคัมภีร์บนเว็บนี้ แล้วอยากรู้ว่าถ้อยคำที่เห็นมาจากใคร

**I want to** เปิดหน้าเดียวแล้วเห็นครบว่าเว็บนี้หยิบของมาจากที่ไหนบ้าง ใครเป็นเจ้าของ และเจ้าของอนุญาตให้ทำอะไรได้แค่ไหน

**So that** เชื่อสิ่งที่อ่านได้เพราะเดินไปดูต้นทางเองได้ ไม่ใช่เพราะเว็บบอกให้เชื่อ

## Acceptance criteria

* เปิดหน้านี้แล้ว **เห็นทุกแหล่งที่เว็บใช้จริง** พร้อมชื่อเจ้าของและชื่อสัญญา โดยไม่ต้องเข้าสู่ระบบ
* แต่ละแหล่ง **บอกด้วยว่าผู้อ่านได้อะไรจากมัน** ด้วยคำที่เด็ก ป.4 อ่านรู้เรื่อง ⛔ ไม่ใช่ศัพท์ของช่าง
* **กดท่อนที่มาของแหล่งไหน ก็ไปถึงหน้าของเจ้าของจริง** จึงตรวจได้เองว่าเราไม่ได้แต่งขึ้นมา
* **ประโยคเครดิตที่เจ้าของบังคับ ต้องปรากฏบนหน้านี้ครบทุกแหล่งที่บังคับ** ตกแม้แหล่งเดียวคือผิดสัญญา
  รายชื่อว่าแหล่งไหนบังคับบ้าง เจ้าของคือ [บันทึกแหล่งข้อมูล หัวข้อ ②](../บันทึก-แหล่งข้อมูล.md) ⛔ ไม่นับซ้ำที่นี่
* **อ่านออกและกดถูกทั้งบนจอคอมและบนมือถือ** จอแคบสุดที่รับคือ 320 จุด และต้องไม่ต้องเลื่อนซ้ายขวา
* **แผนภาพที่เล่าว่าของเดินจากไหนไปไหน ต้องอ่านตัวหนังสือในภาพออก** บนทุกจอ
* ทางที่ผิดพลาด — **แผนภาพวาดไม่ขึ้น** ผู้อ่านต้องยังเห็นรายการแหล่งครบทุกแหล่ง ⛔ ห้ามหน้าว่างและห้ามค้าง

## Security measures

N/A — หน้านี้อ่านอย่างเดียว ไม่มีช่องให้กรอก ไม่รับข้อมูลจากผู้อ่าน และไม่มีกุญแจอยู่ในหน้า

## Notes

**ขอบเขตและเกณฑ์พร้อมของทั้งโครงการ** อยู่ที่ [ภารกิจ WPA.08](../wpa-08-mission-statement.md) ⛔ ไม่เขียนซ้ำที่นี่

**เหตุที่หน้านี้ต้องมี ไม่ใช่ของแถม** — แหล่งที่เราใช้อยู่ใต้สัญญาแบบ CC ที่บังคับให้บอกว่าเอามาจากใคร ไม่บอกคือผิดสัญญา

**รอบนี้ยังไม่ทำ** — ช่องค้นหาในหน้า · เรียงหรือกรองตามชนิดสัญญา · หน้าแยกของแต่ละแหล่ง
เหตุผลคือวันนี้มี 11 แหล่ง ผู้อ่านเลื่อนดูจบในหน้าเดียว ของพวกนี้จะคุ้มเมื่อรายการยาวกว่านี้มาก

* [x] **N**egotiable — ถ้อยคำในใบเป็นจุดตั้งต้น พี่เอมแก้ได้
