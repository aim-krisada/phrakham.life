# เลือกความหมายให้ตรงกับคำในข้อ

ข้างล่างมี 5 ข้อ แต่ละข้อยกข้อความต้นฉบับมาให้ พร้อมชี้คำหนึ่งคำในข้อนั้น
แล้วให้ตัวเลือกความหมายมาหลายอัน **ตัวเลือกทุกอันเป็นความหมายที่พจนานุกรมให้กับคำนั้นจริง**
งานของคุณคือตอบว่า **คำนั้นในข้อนั้นใช้ความหมายตัวเลือกไหน**

กติกาการตอบ ⛔ ห้ามอธิบายยาว
- ตัดสินจาก **บริบทของข้อในต้นฉบับ** เป็นหลัก ใช้ HALOT (Koehler-Baumgartner) ช่วยได้ ⛔ ห้ามใช้ BDAG เพราะนั่นเล่มกรีก
- ตอบเป็นตารางเท่านั้น 3 คอลัมน์ คือ  เลขข้อสอบ | ตัวอักษรที่เลือก | เหตุผลไม่เกิน 12 คำ
- **ถ้าไม่มีตัวเลือกไหนเข้ากับคำนั้นในข้อนั้นเลย ให้ตอบ X** ⛔ ห้ามเลือกอันที่ใกล้ที่สุดแทน
- เลือกได้ตัวเดียวต่อข้อ

--- ข้อสอบ 6
ที่อยู่: EXO 27:1
ข้อความต้นฉบับ: וְעָשִׂ֥יתָ אֶת־הַמִּזְבֵּ֖חַ עֲצֵ֣י שִׁטִּ֑ים חָמֵשׁ֩ אַמּ֨וֹת אֹ֜רֶךְ וְחָמֵ֧שׁ אַמּ֣וֹת רֹ֗חַב רָב֤וּעַ יִהְיֶה֙ הַמִּזְבֵּ֔חַ וְשָׁלֹ֥שׁ אַמּ֖וֹת קֹמָתֽוֹ׃
คำที่ถาม: רָב֤וּעַ   (รูปตั้งต้น רָבַע · ชนิดคำ verb)
ตัวเลือก:
  A) action by which humans assume a horizontal position [คำแปลสั้น: to lie down]
  B) literally: to cause to lie down; hence: causative action by which humans cause animals to copulate with each other [คำแปลสั้น: to cause to mate]
  C) state in which an object has four sides of equal size [คำแปลสั้น: square]
  D) literally: to lie down; hence: actions by which humans assume a horizontal position to order to copulate with an animal [คำแปลสั้น: to mate, to have intercourse]
  X) ไม่มีตัวเลือกไหนเข้ากับคำนี้ในข้อนี้
