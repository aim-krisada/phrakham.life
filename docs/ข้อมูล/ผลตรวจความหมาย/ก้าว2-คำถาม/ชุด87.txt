# เลือกความหมายให้ตรงกับคำในข้อ

ข้างล่างมี 4 ข้อ แต่ละข้อยกข้อความต้นฉบับมาให้ พร้อมชี้คำหนึ่งคำในข้อนั้น
แล้วให้ตัวเลือกความหมายมาหลายอัน **ตัวเลือกทุกอันเป็นความหมายที่พจนานุกรมให้กับคำนั้นจริง**
งานของคุณคือตอบว่า **คำนั้นในข้อนั้นใช้ความหมายตัวเลือกไหน**

กติกาการตอบ ⛔ ห้ามอธิบายยาว
- ตัดสินจาก **บริบทของข้อในต้นฉบับ** เป็นหลัก ใช้ HALOT (Koehler-Baumgartner) ช่วยได้ ⛔ ห้ามใช้ BDAG เพราะนั่นเล่มกรีก
- ตอบเป็นตารางเท่านั้น 3 คอลัมน์ คือ  เลขข้อสอบ | ตัวอักษรที่เลือก | เหตุผลไม่เกิน 12 คำ
- **ถ้าไม่มีตัวเลือกไหนเข้ากับคำนั้นในข้อนั้นเลย ให้ตอบ X** ⛔ ห้ามเลือกอันที่ใกล้ที่สุดแทน
- เลือกได้ตัวเดียวต่อข้อ

--- ข้อสอบ 224
ที่อยู่: DAN 12:6
ข้อความต้นฉบับ: וַיֹּ֗אמֶר לָאִישׁ֙ לְב֣וּשׁ הַבַּדִּ֔ים אֲשֶׁ֥ר מִמַּ֖עַל לְמֵימֵ֣י הַיְאֹ֑ר עַד־מָתַ֖י קֵ֥ץ הַפְּלָאֽוֹת׃
คำที่ถาม: מַּ֖עַל   (รูปตั้งต้น מַעַל · ชนิดคำ adverb)
ตัวเลือก:
  A) literally: upwards; hence: process by which time moves on from a particular point [คำแปลสั้น: onward (in time)]
  B) literally: above; hence: state or process by which humans have or achieve a relatively high status [คำแปลสั้น: greater]
  C) literally: upwards; hence: state in which humans have a relatively advanced age [คำแปลสั้น: upwards (in years)]
  D) a referent pointing to a position above a person or object [คำแปลสั้น: upwards, above]
  E) action by which humans do something to (other) humans or deities that is not in line with the behavior that they committed themselves to [คำแปลสั้น: unfaithfulness]
  F) literally: above; hence: state in which an event has an relatively high level of intensity [คำแปลสั้น: more, increasingly]
  X) ไม่มีตัวเลือกไหนเข้ากับคำนี้ในข้อนี้
