# เราทำข้อมูลอย่างไร

**หน้านี้ตอบอะไร** เราเอาไฟล์ดิบของเจ้าของมาแล้วทำอะไรกับมันบ้าง จนกลายเป็นของที่หน้าเว็บอ่านได้ เล่าทีละแหล่ง ทีละขั้น และบอกวิธีเปิดไฟล์ดูของจริงด้วยตัวเองทุกขั้น

**หน้านี้ไม่ตอบอะไร** ของมาจากใคร และสัญญาว่าอย่างไร สองเรื่องนี้อยู่ที่หน้าแหล่งข้อมูล เขียนซ้ำสองที่เมื่อไร อีกที่จะค้างรุ่นเก่าโดยไม่มีใครรู้

**ตัวเลขในหน้านี้มาจากไหน** อ่านจากไฟล์จริงตอนรันสคริปต์ทุกตัว ไม่มีตัวไหนพิมพ์ด้วยมือ รันซ้ำบนเครื่องที่มีกอง _แตก แล้วได้ไฟล์เหมือนเดิมทุกไบต์

**หน้านี้สร้างมาอย่างไร** ตัวสร้างเปิดไฟล์จริงแล้ววัดเอง เขียนผลลง `docs/ข้อมูล/เราทำข้อมูลอย่างไร.json` ด้วย `tools/สร้างเราทำข้อมูลอย่างไร.py` แล้วหน้าที่คุณอ่านอยู่นี้ ปั้นต่อจากไฟล์นั้นด้วย `tools/สร้างเราทำข้อมูลอย่างไร-md.py` ⇒ รันซ้ำได้ผลเดิมทุกไบต์ ⇒ ⛔ ห้ามแก้หน้านี้ด้วยมือ

## เล่าทีละแหล่ง ทีละขั้น

แหล่งหนึ่งแหล่งคือกองข้อมูลหนึ่งกองที่เราเดินด้วยขั้นตอนชุดเดียวกันตั้งแต่ต้นจนจบ ⛔ ไม่ใช่เจ้าของหนึ่งราย ⇒ ส่วนใหญ่หนึ่งแหล่งมีเจ้าของรายเดียว แต่แหล่งตัวบทฉบับเทียบมีเจ้าของสามราย เพราะสามฉบับนั้นเดินขั้นตอนชุดเดียวกัน แยกเล่าทีละรายจึงได้ของซ้ำสามรอบ ⇒ ใครอยากรู้ว่าของมาจากใคร ดูที่หน้าแหล่งข้อมูล แต่ละแหล่งเราทำสี่ขั้น ทุกขั้นบอกห้าอย่าง คือทำอะไร ของเข้าคือไฟล์ไหน ทำด้วยเครื่องมือไหน ของออกคืออะไร และวิธีตรวจเองว่าเปิดที่ไหนแล้วจะเห็นอะไร

### 4. คำที่ต่อความหมายไม่ติด ⇒ ฝั่งหนึ่งรู้เหตุแล้ว อีกฝั่งยังไม่รู้

หน้านี้โชว์ทั้งจำนวนที่ต่อติดและจำนวนทั้งหมด ⇒ ลบกันแล้วเหลือช่องว่างสองจุด คนอ่านจะถามทันทีว่าที่เหลือไปไหน ⇒ ข้อนี้ตอบให้ตรงนี้ จุดหนึ่งเรารู้เหตุแล้ว อีกจุดหนึ่งเรายังไม่รู้ และเราบอกตรง ๆ ว่ายังไม่รู้

  - **ต่อไม่ติด** 180,952
  - **ต่อไม่ติดคิดเป็นร้อยละ** 38.0
  - **เหตุคืออะไร** ตัวหารคือชิ้นคำทุกชิ้น ซึ่งรวมคำเชื่อม คำนำหน้า และสรรพนามต่อท้ายที่ต้นฉบับตัดแยก ⇒ พจนานุกรมไม่เก็บคำพวกนี้อยู่แล้ว เพราะไม่มีความหมายให้อธิบาย ⇒ ตัวเลขที่ดูต่ำจึงไม่ใช่ของหาย
