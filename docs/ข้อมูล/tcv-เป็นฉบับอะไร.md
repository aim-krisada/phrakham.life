# ไฟล์ TCV ที่เราถือ เป็นฉบับอะไรกันแน่

ใบงาน [#58](https://aimgit.aimagin.com/v3/phrakham/-/issues/58) · เขียน 5 ก.ย. 2569

## เอกสารนี้ตอบอะไร

พี่เอมส่งข้อมูลมาว่า ฉบับ Thai Common Language เริ่มโดยสมาคมพระคริสตธรรมไทย
วางฐานตัวบทไว้ตั้งแต่ยุค 1970-1980 ใช้ต้นฉบับ BHS กับ UBS Greek
แต่ไฟล์ที่เราถืออยู่เขียนว่าเจ้าของคือ Biblica, Inc. ปี 2025
ถ้าสองอันนี้เป็นคนละโครงการ ข้อมูลเรื่องต้นฉบับข้างบนใช้กับไฟล์เราไม่ได้

**คำตอบสั้นที่สุด — เป็นคนละฉบับ**
ไฟล์ของเราคือฉบับของ Biblica ไม่ใช่ของสมาคมพระคริสตธรรมไทย
ชื่อคล้ายกันเพราะทั้งคู่มีคำว่า Common แต่คนละเจ้าของ คนละปี

## รันซ้ำได้ทุกตัวเลข

ทุกตัวเลขในเอกสารนี้มาจากสคริปต์ `tools/tcvฉบับไหน.py`
สั่ง `py -3.14 tools/tcvฉบับไหน.py` แล้วผลจะออกเป็น JSON เหมือนที่เก็บไว้ที่
[`tcv-ฉบับไหน.json`](tcv-ฉบับไหน.json) ⛔ ไม่มีตัวเลขไหนพิมพ์ด้วยมือ

## หนึ่ง ไฟล์บอกอะไรเกี่ยวกับตัวเอง

เปิด `metadata.xml` อ่านทั้งไฟล์ แล้วเปิดแฟ้มงาน Paratext ที่ซ้อนอยู่ข้างในซิปด้วย
นี่คือข้อความที่เจ้าของเขียนไว้เอง

| ช่อง | สิ่งที่เขาเขียน |
|---|---|
| ชื่ออังกฤษ | Biblica® Open Thai Common Version 2025 |
| ชื่อไทย | Biblica® พระคริสตธรรมคัมภีร์ ฉบับไทยสามัญแบบเปิด |
| ชื่อย่อ | OTCV |
| รหัสงานแปล | thOTCV25 |
| เจ้าของลิขสิทธิ์ | Biblica, Inc. |
| ปีลิขสิทธิ์ | สงวนลิขสิทธิ์ © 2025 โดย Biblica, Inc. |
| ชนิดงานแปล | Revision |
| ระดับผู้อ่าน | Basic |
| วันที่แปลเสร็จ | 2025-03-01 |

**ชื่อย่อของเขาคือ OTCV ไม่ใช่ TCV** เราตั้งชื่อโฟลเดอร์ว่า `tcv` กันเอง

## สอง ไฟล์บอกไหมว่าเกี่ยวกับสมาคมพระคริสตธรรมไทย

**ไม่บอก และไม่มีร่องรอยเลย**
สคริปต์ค้นทั้งซิป ทั้ง `metadata.xml` แฟ้มงาน Paratext และไฟล์ตัวบททั้ง 66 เล่ม
คำว่า Thailand Bible Society · United Bible Societies · Bible Society ·
สมาคมพระคริสตธรรม · UBS · Good News · BHS · Nestle · Aland · NIV
**เจอศูนย์ครั้งทุกคำ** จำนวนอยู่ในช่อง `จำนวนครั้งที่เจอคำเหล่านี้ในซิปทั้งซิป`

ในไฟล์มีชื่อองค์กรอยู่ชื่อเดียวคือ Biblica, Inc.
ทั้งช่องเจ้าของสิทธิ์ ช่องผู้ดูแลสิทธิ์ และช่องผู้ร่วมทำ เป็น Biblica ทั้งหมด

## สาม ไฟล์บอกไหมว่าแก้มาจากฉบับไหน

**ไม่บอก** เขาเขียนว่าชนิดงานแปลคือ Revision แปลว่าเป็นการแก้ของเดิม
แต่ช่องที่ควรบอกว่าแก้มาจากอะไร ว่างทั้งสองช่อง
ช่อง `relationships` ใน `metadata.xml` ว่างเปล่า
ช่อง `BaseTranslation` ในแฟ้มงาน Paratext ไม่มีค่า
⇒ **เขาไม่เขียน เราจึงตอบด้วยคำประกาศไม่ได้** ต้องวัดจากตัวบทเอาเอง

## สี่ ในเครื่องมีฉบับของสมาคมพระคริสตธรรมไทยให้เทียบไหม

**มี แต่ไม่ใช่ฉบับภาษาไทยกลาง**
ที่ `C:\gl\krisada\phrakham.life2\_resources\mybible-backups` มีฉบับไทย 6 ฉบับ
เป็นของสมาคมพระคริสตธรรมไทย 3 ฉบับ คือ 1971 · OV 83 · ฉบับมาตรฐาน 2011
อีก 3 ฉบับเป็นของเจ้าอื่น คือ อมตธรรมร่วมสมัย 2007 ของ Biblica ·
ฉบับอ่านเข้าใจง่ายของ Bible League · และ Thai KJV ของ Philip Pope

⚠️ **ฉบับภาษาไทยกลาง (ประชานิยม) ของสมาคมพระคริสตธรรมไทย ไม่มีในเครื่อง**
⇒ เทียบตัวต่อตัวกับฉบับที่พี่เอมถามถึงตรง ๆ ไม่ได้

หมายเหตุ ตัวบท TCV ที่อยู่ในเว็บรุ่น 2 ก็ไม่ช่วย เพราะสคริปต์ `etl/convert_bibles.py`
ของรุ่น 2 อ่านจากซิปชื่อ `a62f327aa0179709-rev2-release.zip`
ซึ่งเป็นรหัสเดียวกับไฟล์ที่เราถือ ⇒ เป็นไฟล์เดียวกัน ไม่ใช่ของอิสระ

## ห้า เทียบถ้อยคำแล้วได้อะไร

สุ่มมา 22 ข้อ กระจายทั้งเล่มเดิมเล่มใหม่ ทั้งร้อยแก้วและบทกวี
ตัดป้ายกับช่องว่างออก แล้ววัดว่าตัวอักษรตรงกันแค่ไหน 1.0 คือเหมือนทุกตัวอักษร

| ฉบับที่เอามาเทียบ | ค่าเฉลี่ย | ข้อที่เหมือนทุกตัวอักษร |
|---|---|---|
| อมตธรรมร่วมสมัย 2007 · Biblica | 0.756 | 0 |
| ฉบับมาตรฐาน 2011 · สมาคมพระคริสตธรรมไทย | 0.613 | 0 |
| ฉบับ 1971 · สมาคมพระคริสตธรรมไทย | 0.612 | 0 |
| Thai KJV 2003 · Philip Pope | 0.591 | 0 |
| ฉบับอ่านเข้าใจง่าย · Bible League | 0.521 | 0 |
| OV 83 · สมาคมพระคริสตธรรมไทย | 0.514 | 0 |

อ่านสองอย่างจากตาราง

หนึ่ง **ไม่มีข้อไหนเลยที่ถ้อยคำตรงกับฉบับใดฉบับหนึ่งทุกตัวอักษร**
⇒ OTCV เป็นตัวบทของตัวเอง ไม่ใช่สำเนาของฉบับไหนที่เรามี

สอง **ฉบับที่ใกล้ที่สุดคือฉบับของ Biblica เอง** ห่างจากอันดับสองราว 0.14
ตรงกับที่ไฟล์เขียนว่าเจ้าของคือ Biblica และชนิดงานแปลคือ Revision
⇒ **น้ำหนักเอนไปทางว่า OTCV แก้มาจากงานเดิมของ Biblica ไม่ใช่ของสมาคมพระคริสตธรรมไทย**
⛔ แต่ตัวเลขนี้ยังไม่ใช่ข้อพิสูจน์ เพราะเขาไม่เคยประกาศ

## หก กระทบอะไร

**หนึ่ง ข้อมูลเรื่อง BHS กับ UBS Greek ที่พี่เอมส่งมา ยังใช้กับไฟล์เราไม่ได้**
ข้อมูลนั้นพูดถึงงานของสมาคมพระคริสตธรรมไทย ไฟล์เราเป็นของ Biblica
ตราบใดที่ Biblica ไม่ประกาศว่าใช้ต้นฉบับตัวไหน เราอ้างชื่อต้นฉบับไม่ได้

**สอง ผลวัดของใบ [#57](https://aimgit.aimagin.com/v3/phrakham/-/issues/57) ยังใช้ได้เต็มที่**
เขาวัดจากไฟล์จริงว่าเลขข้อกับเนื้อของ TCV เข้ากับ MACULA ไหม
⛔ เขาไม่ได้อาศัยคำประกาศของเจ้าของเลย ⇒ ใบนี้ไม่ไปแตะผลของเขา
ของที่ใบนี้เติมให้คือ **ฉบับนี้ชื่ออะไร ใครเป็นเจ้าของ**

**สาม สิ่งที่เรายังไม่รู้**

- Biblica แปล OTCV จากต้นฉบับฮีบรูเล่มไหน กรีกเล่มไหน
- OTCV แก้มาจากงานเดิมชิ้นไหนของเขา
- ฉบับภาษาไทยกลางของสมาคมพระคริสตธรรมไทย ถ้อยคำเป็นอย่างไร

**สี่ ถ้าจะหาต่อ หาได้จากไหน**

- เขียนไปถามเจ้าของ ช่องติดต่อที่เขาให้ไว้ในไฟล์คือ `https://open.bible/#feedback`
- หาไฟล์ฉบับภาษาไทยกลางของสมาคมพระคริสตธรรมไทยมาลงเครื่อง แล้วเทียบซ้ำด้วยสคริปต์เดิม

⛔ ใบนี้ไม่ตัดสินแทนพี่เอมว่าจะเลือกทางไหน
