## เอกสารนี้ตอบอะไร

พี่เอมถามว่า "เอาอะไรมาจากไหน และเอาไปใช้อย่างไร" เอกสารนี้ตอบทีละช่องข้อมูล
หนึ่งแถวคือหนึ่งช่องที่เราจะหยิบมาใช้จริง ไม่ใช่ทุกช่องที่มีในไฟล์ต้นทาง

ทุกแถวเปิดไฟล์จริงมาแล้ว และมีคำสั่งให้คนอื่นรันเองเพื่อเห็นค่าเดียวกัน

**ของที่เอกสารอื่นเป็นเจ้าของ เอกสารนี้ชี้ไป ไม่ลอกมา**

| อยากรู้เรื่อง | อ่านที่ |
|---|---|
| แต่ละแหล่งให้อะไรเราได้บ้าง เล่าเป็นเรื่อง | [`docs/13-แหล่งให้อะไรเราได้บ้าง.md`](../13-แหล่งให้อะไรเราได้บ้าง.md) |
| รายชื่อ 11 แหล่งที่ขึ้นเว็บ กับสัญญาของแต่ละแหล่ง | [`content/แหล่งข้อมูล.md`](../../content/แหล่งข้อมูล.md) |
| เลขแหล่ง `#01`-`#15` และแหล่งที่ยกออกจากหน้าเว็บ | [`docs/บันทึก-แหล่งข้อมูล.md`](../บันทึก-แหล่งข้อมูล.md) |
| ช่องไหนเผยแพร่ไม่ได้เพราะติดสัญญา | [`docs/บันทึก-แหล่งข้อมูล.md`](../บันทึก-แหล่งข้อมูล.md) หัวข้อ ⑤ และ ⑧ |
| ข้อมูลเดินจากแหล่งไปถึงหน้าจออย่างไร และบรรจบกันตรงไหน | [`ผังการไหล.md`](ผังการไหล.md) |
| เราเอาไฟล์ดิบมาทำอะไรบ้าง ทีละขั้น จนกลายเป็นของที่หน้าเว็บอ่าน | [`เราทำข้อมูลอย่างไร.json`](เราทำข้อมูลอย่างไร.json) ⇒ สร้างด้วย `tools/สร้างเราทำข้อมูลอย่างไร.py` |

## อ่านตารางนี้อย่างไร

**เลขแหล่ง** ยืมมาจาก [`docs/บันทึก-แหล่งข้อมูล.md`](../บันทึก-แหล่งข้อมูล.md) ไม่ได้ตั้งเลขชุดใหม่

อยู่ท้ายตารางและมีป้ายกำกับไว้

**ช่องวิธีดูของจริง** เป็นคำสั่งสั้น ๆ ที่ใช้ชื่อย่อของไฟล์ ตั้งชื่อย่อก่อนหนึ่งครั้งด้วยก้อนข้างล่างนี้

**ช่องใช้ทำอะไรบนหน้าจอ** แถวไหนที่ยังตอบไม่ได้ เขียนว่ายังไม่รู้ ไม่ตัดทิ้งเงียบ ๆ
