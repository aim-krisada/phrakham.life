# ความกว้างคอลัมน์บนจอกว้าง — ก่อนแก้และหลังแก้ใบ #102

## วัดยังไง

1. **วัดเมื่อ 24 ต.ค. 2569** ⇒ เครื่อง Windows 11 · Chromium ของ Playwright 1.62.1 แบบไร้หน้าจอ · ฟอนต์ Sarabun ที่ฝากมากับเว็บ
2. **เครื่องมือคือ `tools/วัดคอลัมน์อ่าน.mjs`** ⇒ ตัวเดียวกันทั้งก่อนแก้และหลังแก้ ⇒ รันซ้ำได้ด้วย `node tools/วัดคอลัมน์อ่าน.mjs <ที่อยู่เว็บ>`
- 2.1 ก่อนแก้ = เว็บที่สร้างจาก main ที่ 2e25dfe ⇒ หลังแก้ = เว็บที่สร้างจากกิ่งของใบ #102
3. **หน้าที่วัด** ⇒ ยอห์น 1 ⇒ เปิด N ฉบับเรียง TCV · THKJV · WEB · LSV ⇒ ตอนที่เอามาเทียบคือ มาระโก 1 · ลูกา 1 · มัทธิว 1 ฉบับ TCV
4. **ตัวอักษรต่อบรรทัด** ⇒ นับเฉพาะตัวที่กินความกว้าง จากบรรทัดที่วาดจริง ⇒ นิยามเดียวกับ `tools/ด่านจังหวะการอ่าน.mjs` ข้อ ③ ⇒ ตัดบรรทัดสุดท้ายของทุกกล่องทิ้ง ⇒ ตัวเลขคือ **ค่ากลาง (มากสุด)**
5. **ห่อ N แถว** ⇒ มีคอลัมน์ไปอยู่ใต้คอลัมน์อื่น ⇒ ฉบับของที่เดียวกันห่อในข้อเดียวกัน · ตอนเทียบห่อไปอยู่ใต้ฝั่งหลัก
6. ⚠️ **จอ 375 เปิดหลายฉบับเห็นฉบับเดียว** ⇒ จอแคบอ่านทีละฉบับเป็นค่าตั้งต้น (ใบ #76 · #97) ⇒ ใบ #102 ⛔ ไม่ได้แตะ
