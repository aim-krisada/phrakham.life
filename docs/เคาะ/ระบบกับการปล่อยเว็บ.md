สารบัญของทุกกองอยู่ที่ [`../สิ่งที่เคาะแล้ว.md`](../%E0%B8%AA%E0%B8%B4%E0%B9%88%E0%B8%87%E0%B8%97%E0%B8%B5%E0%B9%88%E0%B9%80%E0%B8%84%E0%B8%B2%E0%B8%B0%E0%B9%81%E0%B8%A5%E0%B9%89%E0%B8%A7.md)

## ⭐ ขึ้นเว็บที่ GitHub + Cloudflare และ **ต้องล็อกอินก่อนเข้า** (พี่เอมเคาะ 6 ก.ย. 2569)

**พี่เอมสั่งว่า** *"so GitHub + cloudfare must lockin"*

⇒ ซอร์สอยู่ GitHub · ขึ้นเว็บที่ Cloudflare · มีตัวกั้นบังคับล็อกอินก่อนเข้า
ปัญหาที่ข้อนี้แก้ ⇒ พี่เอมตรวจงานจากมือถือตอนอยู่นอกบ้าน ลิงก์ในเครื่องใช้ไม่ได้

ทางที่ ⛔ ไม่เอา ⇒ **หน้าเว็บของ GitHub** เพราะหน้าที่เสิร์ฟออกมาเป็นสาธารณะ บังคับล็อกอินต้องจ่ายเพิ่ม
· **หน้าเว็บของอัมกิต** ทำได้จริงแต่ต้องดันซอร์สกลับไปอัมกิต ⇒ ได้ของเดียวกัน 2 ที่

### ⭐ ข้อนี้ปลดล็อกเรื่องที่เคยกั้นไว้

31 ส.ค. 2569 เคาะไว้ว่ายังไม่เปิดให้คนนอกเข้า เพราะ `content/แหล่งข้อมูล.md` สัญญาความสามารถที่ยังทำไม่ได้
⇒ พอมีตัวกั้นล็อกอิน คนนอกเข้าไม่ได้อยู่แล้ว เหตุผลนั้นหมดไป
⇒ ⛔ แต่นี่ยังไม่ใช่การเปิดให้คนทั่วไป ⇒ วันที่จะเปิดจริงต้องกลับมาดูเรื่องคำสัญญาเกินจริงอีกรอบ

**สิ่งที่ต้องทำ และใครทำ** ⇒ **พี่เอมเท่านั้น** ⇒ ตั้งตัวกั้นล็อกอินที่ Cloudflare กับใส่อีเมลที่อนุญาต · ผูกชื่อโฮสต์ให้ตัวเว็บ เช่น `v3.phrakham.life` ⛔ AI ไม่แตะสองอย่างนี้
**AI** ⇒ จดที่อยู่ที่ได้ลงที่เก็บ

## ⭐ stack ที่ใช้สร้างเว็บ (พี่เอมกำหนด 6 ก.ย. 2569)

> ⭐ **เจ้าของความจริงเรื่อง stack คือ `v3/way` → [`stack.md`](https://aimgit.aimagin.com/v3/way/-/blob/main/stack.md)** ⇒ พี่เอมเคาะไว้ตั้งแต่ **1 ส.ค. 2569** ⛔ ไม่คัดตารางมาวางที่นี่
>
> ย่อให้พอใช้ตัดสินใจ ⇒ โครงเว็บใช้ **Nuxt** · หน้าตาใช้ **Tailwind** · ชิ้นส่วนหน้าจอใช้ **shadcn-vue** · ⛔ ไม่ต้องมีคลังข้อมูลบนเน็ต

ท่ายกมาจาก `v3/pleng` ที่ใช้ชุดนี้อยู่จริงแล้ว ⇒ ค่ารุ่นกับค่าตั้งของจริงอยู่ที่ `package.json` และ `nuxt.config.ts` ⛔ ไม่จดซ้ำที่นี่

### ⛔ ชิ้นส่วนไหนมีใน shadcn-vue ให้ใช้ตัวนั้น ⛔ ห้ามเขียน ARIA เอง

การ์ดคำอธิบายท้ายข้อใช้ **Collapsible** · แผ่นตั้งค่าการอ่านใช้ **Sheet** บนมือถือกับ **Popover** บนจอคอม · ปุ่มการจัดวาง 3 ตัวใช้ **ToggleGroup**
เปิดปิดเลขบทข้อกับหัวข้อย่อยใช้ **Switch** · หน้าต่างเลือกเล่มใช้ **Dialog** · เมนู 3 หัวใช้ **Sheet** บนมือถือกับ **NavigationMenu** บนจอคอม · เม็ดยาบทความใช้ **Badge** ที่กดได้ · บัญชีคำอธิบายท้ายบทใช้ **Card**

### ⛔ ของรุ่น 2 ยืมได้เฉพาะ JS ⛔ ห้ามยืมไฟล์สไตล์

`pk-fontsize.js` ยืมตรง ๆ ได้ เพราะเป็น JS ล้วน ตั้งค่าตัวแปร CSS
`pk-expand.css` ⛔ ห้ามยืมทั้งไฟล์ เพราะเป็นสไตล์กลางลอยทั้งเว็บ ขัดกับเหตุผลที่เลือก Tailwind ⇒ ยืมหน้าตากับพฤติกรรม แล้วเขียนใหม่เป็น Collapsible + Tailwind

### ⛔ สัญลักษณ์บนคำใช้ไอคอน lucide ⛔ ไม่ใช้อีโมจิ

อีโมจิหน้าตาไม่เหมือนกันในแต่ละเครื่อง ⇒ ผู้อ่านคนละเครื่องเห็นคนละอย่าง · ไอคอน lucide เป็นเส้นวาด เหมือนกันทุกเครื่อง

## PWA

- **ทำ แต่ v1 ทำแค่ครึ่งเดียว** ⇒ ใส่ไฟล์แนะนำแอปให้ติดตั้งเป็นไอคอนได้ ⛔ ยังไม่ใส่ตัวเก็บออฟไลน์
- ⭐⭐ **iPhone ลบข้อมูลที่เว็บเก็บไว้ทิ้งหลัง 7 วันที่ไม่ได้เข้าเว็บ และลบทั้งก้อนพร้อมกัน** ⇒ ทางรอดเดียวคือต้องกด "เพิ่มไปที่หน้าจอโฮม" ก่อน ⇒ แต่ iPhone ไม่มีปุ่มให้กดติดตั้ง
- ⛔ อย่าใช้เครื่องมือ PWA สำเร็จรูปของ Nuxt ⇒ ค่าเริ่มต้นจะโหลดหน้าเว็บทั้ง 1,189 บทตั้งแต่คนเข้าครั้งแรก
- ⚠️ **กับดักค้างรุ่นเก่า** ⇒ ต้อง `Cache-Control: no-cache` ที่ `sw.js` · ห้ามเปลี่ยนชื่อไฟล์ · หน้าเว็บใช้ network-first · ⛔ ไม่ใช้ skipWaiting อัตโนมัติ · เตรียมปุ่มฉุกเฉินไว้ตั้งแต่วันแรก
- **คำที่ใช้** ⇒ **"อ่านได้ตอนไม่มีเน็ต"** ⛔ ห้าม **"ใช้ได้ตอนไม่มีเน็ต"** เพราะเสียง 265 MB เก็บไม่ไหว

### โหลดเก็บไว้ในเครื่อง — **พี่เอมเคาะรูปของฟีเจอร์ 6 ก.ย. 2569** ⇒ ใบงาน [#70](https://aimgit.aimagin.com/v3/phrakham/-/issues/70)

- **แบ่งให้โหลดทีละฉบับแปล** · ภาษาเดิมเป็นก้อนแยก ⛔ ห้ามแบ่งเป็นชั้นข้อมูล เพราะผู้อ่านต้องเห็นชื่อฉบับที่เขารู้จัก
- **ปุ่มที่ต้องมี 3 อย่าง** ⇒ โหลดทั้งหมด · ลบทีละอัน · ลบทั้งหมด
- ⭐ **แบ่งเป็นไฟล์เล็ก ๆ ⛔ ไม่ใช่ก้อนใหญ่ก้อนเดียว** เพราะเน็ตสะดุด ⇒ ก้อนใหญ่สะดุดคือเสียทั้งก้อน · ⛔ ของชุดเดียว ห้ามทำไฟล์สองชุดคนละขนาด
  ⇒ **ตรวจได้ด้วยเครื่อง** ⇒ ปิดเน็ตกลางคันแล้วเปิดใหม่ ต้องเดินต่อจากไฟล์ถัดไป
- ⭐ **เรื่องไอโฟนลบทิ้งใน 7 วัน ⛔ ไม่เอามาเป็นประเด็นตัดสินอีกต่อไป** ⇒ ทำคู่มือบอกผู้อ่านว่าต้องกดเพิ่มไอคอนก่อน แล้วจบ ⇒ ข้อเท็จจริงข้างบนยังจริงอยู่ เปลี่ยนแค่วิธีแก้

3. **ที่ทดลองเปิดสาธารณะค้างไว้** ⇒ พี่เอมเคาะ *"ไม่เป็นไร เปิดไว้ ทดสอบง่ายดี"* ⇒ ⛔ **ห้ามถามซ้ำ ⛔ ห้ามปิดเอง**
   ⇒ `v3/phrakham` กับ `v3/pleng` ตั้ง `pages_access_level = public` ⇒ ใครรู้ที่อยู่ก็อ่านได้ ⛔ ไม่ต้องล็อกอิน
   ⇒ ทุกหน้ามี `noindex` ⇒ **ค้นจากกูเกิลไม่เจอ**
