## ตั้งโต๊ะ ⇒ ครั้งเดียว

โต๊ะคือ worktree แยกของที่เก็บ GitHub ⇒ ⛔ ห้ามใช้โต๊ะที่คนทำงานอยู่ ⇒ สคริปต์ล้างโต๊ะทุกคืน

```bash
git -C ~/gh/aim-krisada/phrakham.life worktree add --detach ~/gh/aim-krisada/phrakham.life-nightly origin/v3
```

## ตั้งงานตั้งเวลา ⇒ systemd ของผู้ใช้

`~/.config/systemd/user/phrakham-tts-nightly.service`

```ini
[Unit]
Description=ทำเสียง TCV รายคืน (ใบ #171)

[Service]
Type=oneshot
Environment=PHRAKHAM_LIFE2_ETL=%h/aimgit.aimagin.com/krisada/phrakham.life2/etl
Environment=PHRAKHAM_FFMPEG_DIR=/usr/bin
ExecStart=/usr/bin/python3 %h/gh/aim-krisada/phrakham.life-nightly/tools/ทำเสียงTCVรายคืน.py
```

`~/.config/systemd/user/phrakham-tts-nightly.timer`

```ini
[Unit]
Description=ทำเสียง TCV ตี 3 ครึ่งทุกคืน

[Timer]
OnCalendar=*-*-* 03:30:00
Persistent=true

[Install]
WantedBy=timers.target
```

`Persistent=true` ⇒ คืนที่เครื่องหลับอยู่ตอนตี 3 ครึ่ง ⇒ รันทันทีที่เครื่องตื่น

```bash
systemctl --user daemon-reload
systemctl --user enable --now phrakham-tts-nightly.timer
loginctl enable-linger "$USER"
```

`enable-linger` ⇒ งานรันได้แม้ไม่มีใครล็อกอินค้างไว้
