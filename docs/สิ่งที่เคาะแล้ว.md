# สิ่งที่เคาะแล้ว

พี่เอมเคาะไว้แล้ว ⛔ **ห้ามถามซ้ำ ห้ามรื้อ** ถ้าจะเปลี่ยนต้องให้พี่เอมสั่งเอง

> ทำไมมีไฟล์นี้ — พี่เอมบอกว่า *"ผมอาจต้องเหนื่อยหน่อยบอกคุณว่าเราเคยทำอะไรได้ เพราะคุณเริ่มใหม่จริง"*
> ⇒ ทุกอย่างที่พี่เอมเคาะ ให้จดไว้ทันที คนที่มาทำต่อจะได้ไม่ถามซ้ำอีก

**ไฟล์นี้เป็นสารบัญ ⛔ ไม่ใช่ที่เขียนเนื้อ** ⇒ เนื้ออยู่ใน 4 ไฟล์ข้างล่าง แบ่งตามหน้าที่งาน
⇒ **ทำไมแยก** ⇒ คนละสายจดคนละไฟล์ก็ไม่ชนกัน (8 ก.ย. 2569 ชนกัน 3 ครั้งใน 2 วัน เพราะทุกคนต่อท้ายไฟล์เดียวกัน · ใบงาน [#85](https://aimgit.aimagin.com/v3/phrakham/-/issues/85))
