## ทำไมต้องทำ

1. เสียงอ่านพระคำจะใหญ่ขึ้นทุกคืน ⇒ ครบทั้งเล่มฉบับหนึ่งราว 1.5 ถึง 1.9 GB
2. GitHub Pages ให้ที่ละ 1 GB ⇒ จึงแบ่งเป็นฉบับละ 3 ที่
3. แต่ละฉบับมีที่เก็บของตัวเอง ⇒ ชื่อฉบับอยู่ในชื่อที่เก็บ ⇒ ไม่ปนกัน
4. วันนี้มีเสียง 4 ฉบับ ⇒ TCV · THKJV · WEB · LSV ⇒ รวม 12 ที่เก็บ
5. AI ทำเครื่องมือไว้ครบแล้ว ⇒ ขาดแค่ที่เก็บ 12 ที่ กับกุญแจ 1 ดอก
6. สองอย่างนี้ AI ทำเองไม่ได้ ⇒ เป็นของบัญชีพี่เอม

## ขั้นที่ 2 ⇒ ออกกุญแจ 1 ดอก

กุญแจดอกเดียวใช้ได้ทั้ง 13 ที่ ⇒ ที่เก็บเสียง 12 ที่ และ phrakham.life

1. ไปที่ Settings ⇒ Developer settings ⇒ Personal access tokens ⇒ Fine-grained tokens
2. กด Generate new token
3. Token name ⇒ `phrakham-ai`
4. Expiration ⇒ 1 ปี ⇒ จดวันหมดอายุไว้ด้วย
5. Resource owner ⇒ aim-krisada
6. Repository access ⇒ เลือก **Only select repositories**
7. ติ๊กที่เก็บเสียงทั้ง 12 ที่ในตารางข้างบน ⇒ แล้วติ๊ก phrakham.life อีกที่ ⇒ รวม 13 ที่
8. ⛔ ต้องสร้างที่เก็บในขั้นที่ 1 ให้ครบก่อน ⇒ ไม่งั้นจะหาชื่อมาติ๊กไม่เจอ
9. Permissions ⇒ ให้แค่ 2 อย่าง

| สิทธิ์ | ตั้งเป็น |
|---|---|
| Contents | Read and write |
| Pages | Read and write |

10. Metadata จะขึ้นเป็น Read-only เอง ⇒ ปล่อยไว้
11. ⛔ อย่าให้สิทธิ์อื่น ⇒ ให้น้อยที่สุดปลอดภัยที่สุด
12. กด Generate ⇒ คัดลอกกุญแจไว้ ⇒ GitHub แสดงให้เห็นครั้งเดียว

⚠️ **เปิด Pages ครั้งแรก ต้องมีสิทธิ์ Administration เพิ่มชั่วคราว**
1. GitHub ให้เปิด Pages ได้ต่อเมื่อกุญแจมีทั้ง Pages และ Administration แบบ Read and write ⇒ เจอจริง 16 พ.ย. 2569 ⇒ ได้ 403
2. ตอนจะให้ AI เปิด Pages ⇒ Edit กุญแจ ⇒ Add permissions ⇒ Administration ⇒ Read and write ⇒ Update
3. AI บอกว่าเปิดครบแล้ว ⇒ กลับมากดกากบาทที่ Administration ⇒ Update ⇒ เหลือ 2 สิทธิ์ตามตารางข้างบน
4. ส่งไฟล์รายคืนใช้แค่ Contents ⇒ ไม่ต้องมี Administration อีก

1. เปิดไฟล์ `D:\OneDrive\4 Personal\claude\.env`

4. ถ้ายังไม่มีบรรทัดนี้ ⇒ เพิ่มบรรทัดใหม่ ⇒ `GITHUB_TOKEN_PHRAKHAM=` ตามด้วยกุญแจ ⇒ ไม่ต้องมีช่องว่าง

## ขั้นที่ 4 ⇒ บอก AI ว่าเสร็จแล้ว

พิมพ์บอกในใบ #171 ว่า *กุญแจกับที่เก็บพร้อมแล้ว* ⇒ AI ทำต่อเองตามนี้

1. ส่งเสียงแต่ละฉบับขึ้นที่เก็บของฉบับนั้น ⇒ เปิด Pages ให้

3. ครบแล้วค่อยเปลี่ยนเว็บให้ใช้เสียงจาก GitHub ⇒ เปิดคำขอรวมให้ตรวจ
4. ต่อจากนั้น งานทำเสียงรายคืนจะส่งเสียงใหม่ขึ้น GitHub เองทุกคืน
