## 🚨 ผมเขียนแผนนี้บนข้อมูลผิด — แก้แล้ว 6 ก.ย. 2569

**ผมเขียนไว้ว่า** *"ซอร์สที่อัมกิตเป็นตัวเก่า ยังไม่มีหน้าอ่าน ไม่มีตัวบทไทย"* ⇒ **⛔ ไม่จริง**

**ผมไปเปิดของจริงที่อัมกิตแล้ว** ⇒ **อัมกิตคือโปรเจกต์ตัวจริงที่ยังเดินอยู่ทุกวัน**

| ของที่อัมกิตมี | GitHub `phrakham3` มีไหม |
| --- | --- |
| หน้าอ่านครบเส้นทาง `app/pages/read/[book]/[chapter].vue` + หน้าสารบัญ | ⛔ มีแค่หน้าแรกบทเดียวที่ผมทำวันนี้ |
| หน้าต่างเลือกพระธรรม · ตัวปรับขนาดตัวอักษร | ⛔ ไม่มี |
| โค้ดฝั่งเซิร์ฟเวอร์ `server/api/chapter/...` + ซองข้อมูล `_data/*.gz` | ⛔ ไม่มี ⇒ ใช้ไฟล์ JSON แยกบทแทน |
| เครื่องมือ ETL ราว 30 ตัว | ⛔ มี 6 ตัว และส่วนใหญ่เป็นสำเนาของด่านตรวจ |
| งานที่ทำวันนี้ ⇒ เชิงอรรถ · คำพระเยซู · ตรวจปุ่มกระโดด | ⛔ ไม่มี |
| Tailwind + shadcn-vue | ⭐ **มีเฉพาะที่ GitHub** |

⇒ ⭐ **แผนที่ถูกจึงกลับด้าน** ⇒ **อัมกิตเป็นฐาน** ⛔ ไม่ใช่เอา `phrakham3` ไปทับ
⇒ **ของที่ต้องขนไปคือเอกสารออกแบบ** ⛔ ไม่ใช่โค้ด ⇒ โค้ดหน้าอ่านที่ผมเขียนวันนี้ **ซ้ำกับของที่อัมกิตมีดีกว่าอยู่แล้ว**
